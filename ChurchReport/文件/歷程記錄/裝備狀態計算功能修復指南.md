# 裝備狀態計算功能修復指南

## 問題分析
編譯錯誤：`error CS1038: 必須是 #endregion 指示詞`

這是因為 #region 和 #endregion 不匹配導致的。

## 修復步驟

### 步驟 1：檢查檔案結構
打開 `ChurchReport\WebServiceConnector\DownloadIntegrateData.cs` 檔案，檢查所有 #region 和 #endregion 是否配對。

### 步驟 2：確認已添加的方法
在檔案末尾的 #endregion 之前應該有以下方法：

```csharp
        #region 工具區
        /// <summary>
        /// 計算連絡人的裝備狀態
        /// 顯示「本階段可以結業」值為 TRUE 的上課紀錄單
        /// </summary>
        /// <param name="contactId">連絡人ID</param>
        /// <returns>裝備狀態文字（可結業的課程清單）</returns>
        private string CalculateEquipmentStatusForContact(Guid contactId)
        {
            try
            {
                // 取得該連絡人的所有上課紀錄
                var storLessonsCollection = m_ToolUtilityClass.RetrieveManyToOneRelationship(
                    "contact", "contactid", contactId.ToString(), 
                    "new_contact_new_stor_lessons", "new_stor_lessons");

                if (storLessonsCollection == null || storLessonsCollection.Entities.Count == 0)
                {
                    return ""; // 沒有上課紀錄
                }

                // 關鍵課程階段清單
                string[] keyStages = new string[] 
                { 
                    "E1", "E2", "E3", "成長班", "門徒班", "領袖班", 
                    "福上", "福中", "福下" 
                };

                // 收集可以結業的課程階段
                var graduatableStages = new List<string>();

                foreach (var storLessonsEntity in storLessonsCollection.Entities)
                {
                    // 取得完整的上課紀錄實體
                    var storLesson = m_ToolUtilityClass.RetrieveEntity("new_stor_lessons", storLessonsEntity.Id);

                    // 檢查「本階段是否可以結業」
                    bool canGraduate = m_ToolUtilityClass.GetEntityBoolAttribute(storLesson, "new_current_complete");

                    if (canGraduate)
                    {
                        // 取得課程相關資訊
                        var discipleLessonId = m_ToolUtilityClass.GetEntityLookupAttribute(storLesson, "new_new_disciple_lessons_new_stor_les");
                        
                        if (discipleLessonId != null && discipleLessonId != Guid.Empty)
                        {
                            var discipleLessonEntity = m_ToolUtilityClass.RetrieveEntity("new_disciple_lessons", discipleLessonId);
                            
                            if (discipleLessonEntity != null)
                            {
                                string stageName = m_ToolUtilityClass.GetEntityStringAttribute(discipleLessonEntity, "new_now_stage_name");
                                
                                // 只記錄關鍵階段的課程
                                if (!string.IsNullOrEmpty(stageName) && keyStages.Any(stage => stageName.Contains(stage)))
                                {
                                    graduatableStages.Add(stageName);
                                }
                            }
                        }
                    }
                }

                // 去除重複的階段
                var distinctStages = graduatableStages.Distinct().ToList();

                // 組合成裝備狀態文字
                if (distinctStages.Count == 0)
                {
                    return ""; // 沒有可結業的課程
                }
                else if (distinctStages.Count <= 3)
                {
                    return string.Join("、", distinctStages);
                }
                else
                {
                    // 如果課程太多，只顯示前3個並加上「等」
                    return string.Join("、", distinctStages.Take(3)) + "等";
                }
            }
            catch (Exception)
            {
                // 發生錯誤時返回空字串
                return "";
            }
        }

        private bool DoesCaontactQualufied( Entity aContact )
        {
            #region // 連絡人委身類型是否需要顯示裝備狀態

            int aIdentityNumber = this.m_ToolUtilityClass.GetOptionSetAttribute(aContact, "customertypecode");

            if (aIdentityNumber == 100000000 || aIdentityNumber == 100000004 || aIdentityNumber == 100000005 || aIdentityNumber == 100000007 || aIdentityNumber == 100000001 )
            {
                // 以上都不需要顯示
                return false;
            }
            else
            {
                return true;
            }

            #endregion
        }
        #endregion
    }
}
```

### 步驟 3：修改三個地方調用計算方法

#### 3.1 在 GetAllMemberDataFromPresentRecord 方法中
找到以下程式碼：
```csharp

String aEquipmentStatus = "";
```

## 驗證步驟

1. **檢查 #region 配對**
   - 在 Visual Studio 中，使用 Ctrl+M, Ctrl+O 折疊所有 region
   - 檢查是否所有 region 都正確配對

2. **編譯專案**
   - 按 F6 或使用「建置 > 建置解決方案」
   - 確認沒有編譯錯誤

3. **測試功能**
   - 登入系統
   - 查看 MaintainPersonInfomationView
   - 確認裝備狀態顯示「本階段可以結業」的課程
