```

```

1. 檢查 `Startup.cs` 中路由順序
2. 確保特定路由在預設路由之前
3. 檢查 Route 屬性是否衝突

## ?? 路由優先順序說明

ASP.NET Core 路由按照以下順序匹配:

1. **屬性路由** (`[Route]` attribute)
   ```csharp
   [Route("/Login")]
   public IActionResult Login()
   ```

2. **明確定義的路由** (在 `UseMvc` 中)
   ```csharp
   routes.MapRoute(name: "login", template: "Login", ...)
   ```

3. **預設路由** (必須放最後)
   ```csharp
   routes.MapRoute(name: "default", template: "{controller}/{action}/{id?}", ...)
   ```
