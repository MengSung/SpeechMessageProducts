## ?? 重構目標

- **功能**:


## ?? 使用範例

### 前端 JavaScript
```javascript
// 載入信仰狀態清單
$.ajax({
    url: '/Personal/Api/GetSpiritualIdentityList',
    success: function(response) {
        if (response.success && response.data) {
            // 更新下拉選單
            var selectBox = $("#spiritualIdentitySelectBox").dxSelectBox("instance");
            selectBox.option("dataSource", response.data);
        }
    }
});
```

### 後端 C# (數值 → 文字)
```csharp
var optionSetService = new OptionSetMetadataService(
    organizationService,
    logger,
    memoryCache
);

// 100000001 → "基督徒"
string displayText = optionSetService.GetOptionSetText(
    "contact", 
    "new_spiriitual_identity", 
    100000001
);
```

### 後端 C# (文字 → 數值)
```csharp
// "基督徒" → 100000001
int optionValue = optionSetService.GetOptionSetValue(
    "contact", 
    "new_spiriitual_identity", 
    "基督徒"
);
```
