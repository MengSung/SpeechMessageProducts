## 實作邏輯

### 小組長資料網格
對於小組長登入的情況，裝備狀態顯示規則：
```javascript
if (options.data.SmallGroupName && options.data.SmallGroupName.trim() !== '') {
    // 有小組名稱：顯示裝備狀態
    $('<div>').text(options.value || '').appendTo(container);
} else {
    // 沒有小組名稱：不顯示
    $('<div>').text('').appendTo(container);
}
```

### 個人資料網格
對於個人登入的情況，裝備狀態顯示規則：
```javascript
var loginFullName = '@ViewBag.LoginFullName';

if (options.data.SmallGroupName && options.data.SmallGroupName.trim() !== '') {
    // 情況1：有小組名稱 → 顯示所有人的裝備狀態
    $('<div>').text(options.value || '').appendTo(container);
} else if (options.data.FullName === loginFullName) {
    // 情況2：沒有小組 + 是登入者本人 → 顯示自己的裝備狀態
    $('<div>').text(options.value || '').appendTo(container);
} else {
    // 情況3：沒有小組 + 不是登入者本人 → 不顯示
    $('<div>').text('').appendTo(container);
}
```

## 權限控制說明

### 顯示條件矩陣

| 登入類型 | 有小組 | 是本人 | 顯示裝備狀態 |
|---------|--------|--------|--------------|
| 小組長  | 是     | -      | ? 顯示       |
| 小組長  | 否     | -      | ? 不顯示     |
| 個人    | 是     | -      | ? 顯示       |
| 個人    | 否     | 是     | ? 顯示       |
| 個人    | 否     | 否     | ? 不顯示     |

### 資料隱私保護
1. **小組成員**：在有小組的情況下，所有小組成員的裝備狀態都可見
2. **未入組個人**：沒有小組時，只能看到自己的裝備狀態，無法看到其他人的裝備狀態
3. **隱私保護**：防止未入組的個人查看其他未入組人員的裝備資訊
