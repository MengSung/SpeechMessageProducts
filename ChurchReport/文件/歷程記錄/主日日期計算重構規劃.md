# 主日日期計算重構規劃

## 一、需求說明

目前程式碼中「設定主日日期」的邏輯**硬編碼為以星期一為每週第一日**，散佈於 **13 個檔案、至少 17 處**。  
需求：改為依據 `appsettings.json` 中新增的參數 `"每週的第一日"` 來動態計算主日日期。

### 核心規則

> **不論哪天是每週第一日，主日永遠是「星期日」。**  
> **主日 = 該週區間內的那個星期日。**

### 計算規則

| `每週的第一日` | 對應 `DayOfWeek` | 每週區間 | 主日認定 |
|---|---|---|---|
| `"星期六"` | `Saturday` (6) | 星期六 ~ 下週五 | 該區間內的星期日（第 2 天） |
| `"星期日"` | `Sunday` (0) | 星期日 ~ 下週六 | 該區間內的星期日（第 1 天） |
| `"星期一"` | `Monday` (1) | 星期一 ~ 下週日 | 該區間內的星期日（第 7 天） |

### 各設定的週次劃分與主日歸屬

#### ① 每週的第一日 = "星期一"（星期一 ~ 星期日）— 現有行為

```
週次 | 區間                          | 主日
-----|-------------------------------|--------
  W1 | 2/23(一) ~ 3/1(日)            | 3/1
  W2 | 3/2(一)  ~ 3/8(日)            | 3/8
  W3 | 3/9(一)  ~ 3/15(日)           | 3/15
  W4 | 3/16(一) ~ 3/22(日)           | 3/22
  W5 | 3/23(一) ~ 3/29(日)           | 3/29
  W6 | 3/30(一) ~ 4/5(日)            | 4/5
```

#### ② 每週的第一日 = "星期六"（星期六 ~ 星期五）

```
週次 | 區間                          | 主日
-----|-------------------------------|--------
  W1 | 2/28(六) ~ 3/6(五)            | 3/1
  W2 | 3/7(六)  ~ 3/13(五)           | 3/8
  W3 | 3/14(六) ~ 3/20(五)           | 3/15
  W4 | 3/21(六) ~ 3/27(五)           | 3/22
  W5 | 3/28(六) ~ 4/3(五)            | 3/29
```

> 例：3/10(二) → 所屬週 = 3/7(六)~3/13(五) → 主日 = **3/8**（往回看同週的星期日）
> 例：3/6(五) → 所屬週 = 2/28(六)~3/6(五) → 主日 = **3/1**（星期五是該週最後一天）
> 例：3/7(六) → 所屬週 = 3/7(六)~3/13(五) → 主日 = **3/8**（星期六是新一週的第一天）

#### ③ 每週的第一日 = "星期日"（星期日 ~ 星期六）

```
週次 | 區間                          | 主日
-----|-------------------------------|--------
  W1 | 3/1(日)  ~ 3/7(六)            | 3/1
  W2 | 3/8(日)  ~ 3/14(六)           | 3/8
  W3 | 3/15(日) ~ 3/21(六)           | 3/15
  W4 | 3/22(日) ~ 3/28(六)           | 3/22
  W5 | 3/29(日) ~ 4/4(六)            | 3/29
```

> 例：3/10(二) → 所屬週 = 3/8(日)~3/14(六) → 主日 = **3/8**（週首就是主日）
> 例：3/7(六) → 所屬週 = 3/1(日)~3/7(六) → 主日 = **3/1**（星期六是該週最後一天）
> 例：3/8(日) → 所屬週 = 3/8(日)~3/14(六) → 主日 = **3/8**（新一週的第一天就是主日）

### 步驟 2：建立集中式主日計算工具類別

新增檔案：`ChurchReport\Services\SundayCalculator.cs`

```csharp
using System;

namespace ChurchReport.Services;

/// <summary>
/// 集中式主日日期計算服務
/// 根據 appsettings.json 的「每週的第一日」設定，計算給定日期所屬週次的星期日
/// </summary>
public static class SundayCalculator
{
    /// <summary>
    /// 將中文設定值轉換為 System.DayOfWeek
    /// </summary>
    /// <param name="chineseDay">中文星期名稱（"星期日"、"星期一"、"星期六"）</param>
    /// <returns>對應的 DayOfWeek，無效值回傳 Monday（向後相容）</returns>
    public static DayOfWeek ParseChineseDayOfWeek(string chineseDay)
    {
        return chineseDay switch
        {
            "星期日" => DayOfWeek.Sunday,
            "星期一" => DayOfWeek.Monday,
            "星期二" => DayOfWeek.Tuesday,
            "星期三" => DayOfWeek.Wednesday,
            "星期四" => DayOfWeek.Thursday,
            "星期五" => DayOfWeek.Friday,
            "星期六" => DayOfWeek.Saturday,
            _ => DayOfWeek.Monday // 預設值，向後相容既有行為
        };
    }

    /// <summary>
    /// 計算給定日期所屬週次的主日（星期日）
    /// 
    /// 演算法說明：
    /// 1. 根據 firstDayOfWeek 計算 date 距離該週起始日幾天
    /// 2. 回推出該週起始日 (weekStart)
    /// 3. 計算星期日在該週的偏移量
    /// 4. weekStart + 偏移量 = 該週的星期日
    /// 
    /// 範例（2026/3/10 星期二）：
    /// - 每週的第一日 = "星期一"：週起始 = 3/9(一)，偏移 = 6 → 主日 = 3/15
    /// - 每週的第一日 = "星期六"：週起始 = 3/7(六)，偏移 = 1 → 主日 = 3/8
    /// - 每週的第一日 = "星期日"：週起始 = 3/8(日)，偏移 = 0 → 主日 = 3/8
    /// </summary>
    /// <param name="date">任意日期</param>
    /// <param name="firstDayOfWeek">每週第一日（來自設定）</param>
    /// <returns>該週的星期日日期</returns>
    public static DateTime CalculateSunday(DateTime date, DayOfWeek firstDayOfWeek)
    {
        // 1. 計算 date 是「以 firstDayOfWeek 為起始」的第幾天 (0-based)
        int daysSinceWeekStart = ((int)date.DayOfWeek - (int)firstDayOfWeek + 7) % 7;

        // 2. 回推該週起始日
        DateTime weekStart = date.AddDays(-daysSinceWeekStart);

        // 3. 計算星期日在該週的偏移量（第幾天）
        int daysToSunday = ((int)DayOfWeek.Sunday - (int)firstDayOfWeek + 7) % 7;

        // 4. 該週的星期日
        DateTime sunday = weekStart.AddDays(daysToSunday);

        return sunday.Date; // 只取日期，不含時間
    }
}
```

### 演算法推演驗證（以 2026/3/10 星期二為例）

```
■ 每週的第一日 = "星期一" (firstDayOfWeek = 1)
  daysSinceWeekStart = (2 - 1 + 7) % 7 = 8 % 7 = 1
  weekStart = 3/10 - 1 = 3/9 (一) ✓
  daysToSunday = (0 - 1 + 7) % 7 = 6 % 7 = 6
  sunday = 3/9 + 6 = 3/15 (日) ✓

■ 每週的第一日 = "星期六" (firstDayOfWeek = 6)
  daysSinceWeekStart = (2 - 6 + 7) % 7 = 3 % 7 = 3
  weekStart = 3/10 - 3 = 3/7 (六) ✓
  daysToSunday = (0 - 6 + 7) % 7 = 1 % 7 = 1
  sunday = 3/7 + 1 = 3/8 (日) ✓

■ 每週的第一日 = "星期日" (firstDayOfWeek = 0)
  daysSinceWeekStart = (2 - 0 + 7) % 7 = 9 % 7 = 2
  weekStart = 3/10 - 2 = 3/8 (日) ✓
  daysToSunday = (0 - 0 + 7) % 7 = 7 % 7 = 0
  sunday = 3/8 + 0 = 3/8 (日) ✓
```

### 演算法推演驗證（以 2026/3/6 星期五，邊界日為例）

```
■ 每週的第一日 = "星期一" (firstDayOfWeek = 1)
  daysSinceWeekStart = (5 - 1 + 7) % 7 = 11 % 7 = 4
  weekStart = 3/6 - 4 = 3/2 (一) ✓
  daysToSunday = (0 - 1 + 7) % 7 = 6
  sunday = 3/2 + 6 = 3/8 (日) ✓ → 星期五歸下週主日

■ 每週的第一日 = "星期六" (firstDayOfWeek = 6)
  daysSinceWeekStart = (5 - 6 + 7) % 7 = 6 % 7 = 6
  weekStart = 3/6 - 6 = 2/28 (六) ✓
  daysToSunday = (0 - 6 + 7) % 7 = 1
  sunday = 2/28 + 1 = 3/1 (日) ✓ → 星期五歸上週主日（關鍵差異！）

■ 每週的第一日 = "星期日" (firstDayOfWeek = 0)
  daysSinceWeekStart = (5 - 0 + 7) % 7 = 12 % 7 = 5
  weekStart = 3/6 - 5 = 3/1 (日) ✓
  daysToSunday = (0 - 0 + 7) % 7 = 0
  sunday = 3/1 + 0 = 3/1 (日) ✓ → 星期五歸當週主日
```

### 步驟 3：建立設定讀取服務

新增檔案：`ChurchReport\Services\WeeklyScheduleSettings.cs`

```csharp
using System;

namespace ChurchReport.Services;

/// <summary>
/// 每週排程設定（從 appsettings.json 的 "WeeklySchedule" 區段讀取）
/// </summary>
public record WeeklyScheduleSettings
{
    /// <summary>
    /// 每週第一日（中文），預設為 "星期一"（向後相容既有行為）
    /// 可接受的值："星期日"、"星期一"、"星期六"
    /// </summary>
    public string 每週的第一日 { get; init; } = "星期一";

    /// <summary>
    /// 將中文設定值解析為 System.DayOfWeek 列舉
    /// </summary>
    public DayOfWeek GetFirstDayOfWeek()
    {
        return SundayCalculator.ParseChineseDayOfWeek(每週的第一日);
    }
}

/// <summary>
/// 提供靜態存取 FirstDayOfWeek 設定
/// 用於無法透過 DI 注入的舊有類別（如 NewPerson、ListManagementDataManager 等）
/// </summary>
public static class WeeklyScheduleProvider
{
    private static DayOfWeek _firstDayOfWeek = DayOfWeek.Monday;

    /// <summary>
    /// 應用程式啟動時呼叫，初始化設定
    /// </summary>
    public static void Initialize(DayOfWeek firstDayOfWeek)
    {
        _firstDayOfWeek = firstDayOfWeek;
    }

    /// <summary>
    /// 取得每週第一日設定
    /// </summary>
    public static DayOfWeek FirstDayOfWeek => _firstDayOfWeek;
}
```

在 `Startup.cs` 中註冊與初始化：

```csharp
// ConfigureServices 中
services.Configure<WeeklyScheduleSettings>(
    Configuration.GetSection("WeeklySchedule"));

// Configure 中
var weeklySettings = Configuration
    .GetSection("WeeklySchedule")
    .Get<WeeklyScheduleSettings>() ?? new WeeklyScheduleSettings();
WeeklyScheduleProvider.Initialize(weeklySettings.GetFirstDayOfWeek());
```

## 六、測試計畫

### 單元測試

為 `SundayCalculator.CalculateSunday` 建立測試，使用 2026 年 3 月資料：

**每週的第一日 = "星期一"：**
- 3/2(一) → 3/8 ✓
- 3/5(四) → 3/8 ✓
- 3/8(日) → 3/8 ✓
- 3/1(日) → 3/1 ✓
- 3/9(一) → 3/15 ✓

**每週的第一日 = "星期六"：**
- 3/7(六) → 3/8 ✓
- 3/10(二) → 3/8 ✓
- 3/13(五) → 3/8 ✓
- 3/6(五) → 3/1 ✓（邊界！星期五歸上週）
- 3/1(日) → 3/1 ✓
- 3/14(六) → 3/15 ✓

**每週的第一日 = "星期日"：**
- 3/1(日) → 3/1 ✓
- 3/3(二) → 3/1 ✓
- 3/7(六) → 3/1 ✓（邊界！星期六歸當週）
- 3/8(日) → 3/8 ✓
- 3/14(六) → 3/8 ✓

**中文解析測試（`ParseChineseDayOfWeek`）：**
- "星期日" → `DayOfWeek.Sunday` ✓
- "星期一" → `DayOfWeek.Monday` ✓
- "星期六" → `DayOfWeek.Saturday` ✓
- "Monday" → `DayOfWeek.Monday`（fallback） ✓
- "" → `DayOfWeek.Monday`（fallback） ✓
- null → `DayOfWeek.Monday`（fallback） ✓

### 整合驗證

1. 設定 `每週的第一日 = "星期一"` → 行為應與修改前完全相同
2. 設定 `每週的第一日 = "星期六"` → 驗證星期六開始的週報歸屬
3. 設定 `每週的第一日 = "星期日"` → 驗證星期日開始的週報歸屬
