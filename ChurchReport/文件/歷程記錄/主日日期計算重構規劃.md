# 主日日期計算重構規劃

## 一、需求說明

目前程式碼中「設定主日日期」的邏輯**硬編碼為以星期一為每週第一日**，散佈於 **13 個檔案、至少 17 處**。  
需求：改為依據 `appsettings.json` 中新增的參數 `"FirstDayOfWeek"` 來動態計算主日日期。

### 核心規則

> **不論哪天是每週第一日，主日永遠是「星期日」。**  
> **主日 = 該週區間內的那個星期日。**

### 計算規則

| `FirstDayOfWeek` | 每週區間 | 主日認定 |
|---|---|---|
| `"Saturday"` (6) | 星期六 ~ 下週五 | 該區間內的星期日（第 2 天） |
| `"Sunday"` (0) | 星期日 ~ 下週六 | 該區間內的星期日（第 1 天） |
| `"Monday"` (1) | 星期一 ~ 下週日 | 該區間內的星期日（第 7 天） |

### 步驟 1：在 `appsettings.json` 新增設定參數

```json
{
  "WeeklySchedule": {
    "FirstDayOfWeek": "Monday"
  }
}
```

可接受的值：`"Sunday"`、`"Monday"`、`"Saturday"`（字串，對應 `System.DayOfWeek`）。

### 步驟 2：建立集中式主日計算工具類別

新增檔案：`ChurchReport\Services\SundayCalculator.cs`

```csharp
namespace ChurchReport.Services;

/// <summary>
/// 集中式主日日期計算服務
/// 根據 appsettings.json 的 FirstDayOfWeek 設定，計算給定日期所屬週次的星期日
/// </summary>
public static class SundayCalculator
{
    /// <summary>
    /// 計算給定日期所屬週次的主日（星期日）
    /// 
    /// 演算法說明：
    /// 1. 根據 firstDayOfWeek 計算 date 距離該週起始日幾天
    /// 2. 回推出該週起始日 (weekStart)
    /// 3. 計算星期日在該週的偏移量
    /// 4. weekStart + 偏移量 = 該週的星期日
    /// 
    /// 範例（2026/3/10 星期二）：
    /// - Monday 起始：週起始 = 3/9(一)，Sunday 偏移 = 6 → 主日 = 3/15
    /// - Saturday 起始：週起始 = 3/7(六)，Sunday 偏移 = 1 → 主日 = 3/8
    /// - Sunday 起始：週起始 = 3/8(日)，Sunday 偏移 = 0 → 主日 = 3/8
    /// </summary>
    /// <param name="date">任意日期</param>
    /// <param name="firstDayOfWeek">每週第一日（來自設定）</param>
    /// <returns>該週的星期日日期</returns>
    public static DateTime CalculateSunday(DateTime date, DayOfWeek firstDayOfWeek)
    {
        // 1. 計算 date 是「以 firstDayOfWeek 為起始」的第幾天 (0-based)
        int daysSinceWeekStart = ((int)date.DayOfWeek - (int)firstDayOfWeek + 7) % 7;

        // 2. 回推該週起始日
        DateTime weekStart = date.AddDays(-daysSinceWeekStart);

        // 3. 計算星期日在該週的偏移量（第幾天）
        int daysToSunday = ((int)DayOfWeek.Sunday - (int)firstDayOfWeek + 7) % 7;

        // 4. 該週的星期日
        DateTime sunday = weekStart.AddDays(daysToSunday);

        return sunday.Date; // 只取日期，不含時間
    }
}
```

### 演算法推演驗證（以 2026/3/10 星期二為例）

```
■ Monday 起始 (firstDayOfWeek = 1)
  daysSinceWeekStart = (2 - 1 + 7) % 7 = 8 % 7 = 1
  weekStart = 3/10 - 1 = 3/9 (一) ✓
  daysToSunday = (0 - 1 + 7) % 7 = 6 % 7 = 6
  sunday = 3/9 + 6 = 3/15 (日) ✓

■ Saturday 起始 (firstDayOfWeek = 6)
  daysSinceWeekStart = (2 - 6 + 7) % 7 = 3 % 7 = 3
  weekStart = 3/10 - 3 = 3/7 (六) ✓
  daysToSunday = (0 - 6 + 7) % 7 = 1 % 7 = 1
  sunday = 3/7 + 1 = 3/8 (日) ✓

■ Sunday 起始 (firstDayOfWeek = 0)
  daysSinceWeekStart = (2 - 0 + 7) % 7 = 9 % 7 = 2
  weekStart = 3/10 - 2 = 3/8 (日) ✓
  daysToSunday = (0 - 0 + 7) % 7 = 7 % 7 = 0
  sunday = 3/8 + 0 = 3/8 (日) ✓
```

### 步驟 3：建立設定讀取服務

新增檔案：`ChurchReport\Services\WeeklyScheduleSettings.cs`

```csharp
namespace ChurchReport.Services;

/// <summary>
/// 每週排程設定（從 appsettings.json 讀取）
/// </summary>
public record WeeklyScheduleSettings
{
    /// <summary>
    /// 每週第一日，預設為 Monday（向後相容既有行為）
    /// </summary>
    public string FirstDayOfWeek { get; init; } = "Monday";

    /// <summary>
    /// 解析為 System.DayOfWeek 列舉
    /// </summary>
    public DayOfWeek GetFirstDayOfWeek()
    {
        return Enum.TryParse<DayOfWeek>(FirstDayOfWeek, ignoreCase: true, out var result)
            ? result
            : System.DayOfWeek.Monday; // 預設值，向後相容
    }
}

/// <summary>
/// 提供靜態存取 FirstDayOfWeek 設定
/// 用於無法透過 DI 注入的舊有類別
/// </summary>
public static class WeeklyScheduleProvider
{
    private static DayOfWeek _firstDayOfWeek = DayOfWeek.Monday;

    /// <summary>
    /// 應用程式啟動時呼叫，初始化設定
    /// </summary>
    public static void Initialize(DayOfWeek firstDayOfWeek)
    {
        _firstDayOfWeek = firstDayOfWeek;
    }

    /// <summary>
    /// 取得每週第一日設定
    /// </summary>
    public static DayOfWeek FirstDayOfWeek => _firstDayOfWeek;
}
```

在 `Startup.cs` 中註冊與初始化：

```csharp
// ConfigureServices 中
services.Configure<WeeklyScheduleSettings>(
    Configuration.GetSection("WeeklySchedule"));

// Configure 中
var weeklySettings = Configuration
    .GetSection("WeeklySchedule")
    .Get<WeeklyScheduleSettings>() ?? new WeeklyScheduleSettings();
WeeklyScheduleProvider.Initialize(weeklySettings.GetFirstDayOfWeek());
```

DateTime aSunday;
if (DayOfWeek > 0)
{
    aSunday = DateTime.Now.AddDays(-DayOfWeek + 7).ToLocalTime();

else
{
    aSunday = DateTime.Now.AddDays(-DayOfWeek).ToLocalTime();

## 五、向後相容策略

| 面向 | 策略 |
|---|---|
| **未設定參數** | `FirstDayOfWeek` 預設為 `"Monday"`，與現有行為完全一致 |
| **無效值** | `Enum.TryParse` 失敗時 fallback 為 `Monday` |
| **已建立的週報** | 不受影響，改的是「計算哪天是主日」，不是修改已存的資料 |

## 六、測試計畫

### 單元測試

為 `SundayCalculator.CalculateSunday` 建立測試，使用 2026 年 3 月資料：

**Monday 起始：**
- 3/2(一) → 3/8 ✓
- 3/5(四) → 3/8 ✓
- 3/8(日) → 3/8 ✓
- 3/1(日) → 3/1 ✓

**Saturday 起始：**
- 3/7(六) → 3/8 ✓
- 3/10(二) → 3/8 ✓
- 3/6(五) → 3/1 ✓（邊界！星期五歸上週）
- 3/1(日) → 3/1 ✓

**Sunday 起始：**
- 3/1(日) → 3/1 ✓
- 3/3(二) → 3/1 ✓
- 3/7(六) → 3/1 ✓（邊界！星期六歸當週）
- 3/8(日) → 3/8 ✓

### 整合驗證

1. 設定 `FirstDayOfWeek = "Monday"` → 行為應與修改前完全相同
2. 設定 `FirstDayOfWeek = "Saturday"` → 驗證星期六開始的週報歸屬
3. 設定 `FirstDayOfWeek = "Sunday"` → 驗證星期日開始的週報歸屬
