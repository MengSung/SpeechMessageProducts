    <DebugSymbols>true</DebugSymbols>

## ?? 除錯指南

### ? 問題：NETSDK1022 重複項目錯誤

**錯誤訊息：**
```
NETSDK1022: 包含 'Compile' 個重複的項目。
重複的項目為: 'AssemblyInfo.cs'; 'BSUStackTrace.cs'; 'BSUTextWriterTraceListener.cs'
```

**原因：**
SDK-Style 專案會自動包含所有 `.cs` 檔案，但專案檔案中又手動指定了 `<Compile Include="...">`，導致重複。

**解決方案：**
從專案檔案中**刪除**所有 `<Compile Include="..."/>` 項目，只保留：
```xml
<ItemGroup>
  <None Include="SpeechMessageCrmKey.snk" />
</ItemGroup>
```

**詳細除錯步驟：**
查看 `Trace/DEBUG-GUIDE.md` 獲取完整的除錯指南。

## ?? 疑難排解

### 問題 1: PowerShell 執行政策錯誤

**錯誤訊息**:
```
無法載入檔案 Upgrade-Trace-To-Net10.ps1，因為這個系統上已停用指令碼執行。
```

**解決方案**:
```powershell
# 以管理員身份執行
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### 問題 2: 找不到 SpeechMessageCrmKey.snk

**錯誤訊息**:
```
error CS7027: Error signing output with public key from file 'SpeechMessageCrmKey.snk'
```

**解決方案**:
1. 檢查 `SpeechMessageCrmKey.snk` 是否存在於 `Trace\` 目錄
2. 如果不存在，從備份復原或重新產生

### 問題 3: .NET 10 SDK 未安裝

**錯誤訊息**:
```
error NETSDK1045: The current .NET SDK does not support targeting .NET 10.0.
```

**解決方案**:
1. 下載並安裝 [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)
2. 驗證安裝: `dotnet --version`

### 問題 4: Visual Studio 無法載入專案

**錯誤訊息**:
```
The project file cannot be opened by the project system, because it is missing some critical imports...
```

**解決方案**:
1. 確認 Visual Studio 已更新到最新版本
2. 安裝 **.NET desktop development** 工作負載
3. 重新啟動 Visual Studio

### 問題 5: 編譯時出現 CS0006 錯誤

**錯誤訊息**:
```
CS0006: 找不到中繼資料檔 'D:\...\Trace\obj\Debug\net10.0\ref\Trace.dll'
```

**解決方案**:
```powershell
# 清理專案
cd "D:\網頁APP雲端線上版本\DevExpressDevExtreme-21.2.7版本\音訊產品版本\ChurchReport\Trace"
Remove-Item -Recurse -Force obj, bin

# 重新編譯
dotnet build Trace.csproj
```
