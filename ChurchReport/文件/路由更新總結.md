## ?? 常見問題處理

### Q: 更新後出現 404 錯誤?
**A**: 檢查以下項目:
1. 控制器是否已建立?
2. Action 方法名稱是否正確?
3. 路由配置是否正確?
4. 清除瀏覽器快取

### Q: AJAX 呼叫失敗?
**A**: 檢查以下項目:
1. URL 路徑是否正確?
2. Controller/Action 名稱是否正確?
3. 參數傳遞是否正確?
4. 查看瀏覽器開發者工具的網路請求

### Q: DataGrid 無法載入資料?
**A**: 檢查以下項目:
1. `.Controller()` 是否已更新?
2. `.LoadAction()` 方法是否存在?
3. 查看回應的錯誤訊息
4. 檢查 API 端點是否正常
