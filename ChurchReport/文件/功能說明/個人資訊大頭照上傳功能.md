# 個人資訊頁面 - 大頭照上傳功能

## ?? 功能概述

為 `Personal/InfomationView` 新增大頭照上傳功能，允許使用者上傳個人照片並更新 CRM 中 Contact 實體的 EntityImage。

## ?? 功能特點

### 1. 圖片上傳
- ? 支援 JPG、PNG、GIF 格式
- ? 檔案大小限制 5MB
- ? 即時預覽上傳的圖片
- ? 拖曳或點擊上傳
- ? 前端與後端雙重驗證

### 2. CRM 整合
- ? 直接更新 Contact 實體的 `entityimage` 欄位
- ? 自動刷新 Session 中的 Contact 資料
- ? 支援大頭照顯示與下載

### 3. 使用者體驗
- ? 美觀的圓形大頭照顯示
- ? 相機圖示提示上傳
- ? 漸層背景增強視覺效果
- ? Toast 通知上傳狀態
- ? Loading 動畫提示處理中

## ?? 實作細節

### 後端 API (PersonalController.ImageUpload.cs)

#### 1. 上傳大頭照
**端點**: `POST /Personal/UploadContactImage`

**功能**:
1. 驗證上傳檔案（大小、類型）
2. 讀取圖片為 byte[]
3. 更新 CRM Contact 的 `entityimage` 欄位
4. 刷新 Session 中的 Contact 資料
5. 返回上傳結果

**請求參數**:
```csharp
IFormFile imageFile // 上傳的圖片檔案
```

**回應格式**:
```json
{
    "success": true,
    "message": "大頭照上傳成功！",
    "imageUrl": "/Personal/GetContactImage?contactId={guid}&timestamp={timestamp}"
}
```

#### 2. 取得大頭照
**端點**: `GET /Personal/GetContactImage?contactId={guid}`

**功能**:
1. 查詢 CRM Contact 的 `entityimage` 欄位
2. 返回圖片 byte[] 或預設 SVG 圖示

**回應類型**: `image/jpeg` 或 `image/svg+xml`

## ?? 使用方式

### 方法 1: 使用新的 View（推薦）

1. **更新路由**（在 `PersonalController.cs`）:
```csharp
[HttpGet]
[Route("/Personal/PersonalInfomationView")]
[Route("/Personal/InfomationView")]
public IActionResult PersonalInfomationView()
{
    try
    {
        SetupPersonalInfoViewBag();
        InMemoryContext.PersonalInfomationModel.SetPersonalInfomationViewModel();
        
        // ? 設定 ContactId
        var loginContact = InMemoryContext.PersonalInfomationModel.m_LoginContact;
        if (loginContact != null)
        {
            InMemoryContext.PersonalInfomationModel.m_PersonalInfomationViewModel.ContactId = loginContact.Id;
        }
        
        // ? 使用新的 View
        return View("PersonalInfomationViewWithImage", 
            InMemoryContext.PersonalInfomationModel.m_PersonalInfomationViewModel);
    }
    catch (Exception e)
    {
        return HandleError(e, "PersonalInfomationView");
    }
}
```

## ?? 資料流程

```
使用者上傳圖片
    ↓
前端驗證（檔案大小、類型）
    ↓
即時預覽圖片
    ↓
AJAX 上傳到後端
    ↓
後端驗證（再次檢查）
    ↓
更新 CRM Contact.entityimage
    ↓
刷新 Session
    ↓
返回成功訊息
    ↓
前端更新顯示（加時間戳避免快取）
```

## ?? 安全性考量

### 1. 檔案驗證
- ? 檢查檔案大小（限制 5MB）
- ? 檢查檔案類型（只允許圖片格式）
- ? 前端與後端雙重驗證

### 2. 權限控制
- ? 只能更新當前登入使用者的大頭照
- ? 使用 Session 驗證身份
- ? CRM 層級的權限檢查

### 3. 防護措施
- ? 防止 XSS 攻擊（圖片以 byte[] 儲存）
- ? 防止檔案過大導致伺服器問題
- ? 防止不支援的檔案類型
