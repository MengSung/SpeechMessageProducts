## ?? 發現的問題與解決方案

### 問題 1: .NET Framework 4.6.2 不支援 ServiceClient
**現象**: `DataverseServiceClientAdapter.cs` 無法編譯  
**原因**: `PowerPlatform.Dataverse.Client.ServiceClient` 需要 .NET Core 3.1+ 或 .NET 5+

**已套用的解決方案**: ? 加入條件編譯 `#if NETCOREAPP || NET5_0_OR_GREATER`
- 在 .NET Framework 環境下，此檔案會被排除編譯
- 在 .NET Core / .NET 10 環境下，才會編譯此 Adapter

### 問題 2: 舊式 csproj 需要手動加入檔案
**現象**: 新建立的 .cs 檔案未出現在專案中  
**原因**: .NET Framework 4.6.2 使用舊式 csproj 格式，需明確列出每個檔案

**需要手動執行的步驟**: ?? 見下方指引

1. 關閉 Visual Studio

3. 找到 `<Compile Include="ToolUtilityClass.cs" />` 這一行

