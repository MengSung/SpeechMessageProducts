### 類型 C: C# 7.3 語法限制 (2處) ?
修改 switch expression 為 switch statement:
```csharp
// C# 8.0+ (不支援)
return id switch
{
    "區牧" => "race_id",
    _ => null
};

// C# 7.3 (支援)
switch (id)
{
    case "區牧":
        return "race_id";
    default:
        return null;
}
```

**受影響檔案:**
- ListManagementController.cs

### 類型 D: ref 參數問題 (2處) ?
建立局部變數解決 readonly 欄位限制:
```csharp
// 問題: readonly 欄位不能用作 ref 參數
.SavePersonalReportForm(ref ToolUtility, viewModel);

// 解決方案: 建立局部變數
var toolUtility = ToolUtility;
.SavePersonalReportForm(ref toolUtility, viewModel);
```

**受影響檔案:**
- PersonalController.cs
