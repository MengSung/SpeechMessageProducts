# 裝備狀態聯絡人歸屬問題 - 快速參考卡

## ?? 問題識別

**症狀檢查清單**:
- [ ] 某個聯絡人出現在錯誤的小組中
- [ ] 聯絡人在多個小組中重複出現
- [ ] 聯絡人不在應該屬於的小組中

---

## ?? 快速診斷（5 分鐘）

### 1?? 檢查名單成員
```
CRM → 進階尋找 → 名單
→ 新增相關 → 名單成員 → 新增相關 → 聯絡人
→ 篩選: 全名 = "{聯絡人姓名}"
```

### 2?? 檢查出席記錄
```
CRM → 進階尋找 → 個人聚會與靈修記錄
→ 新增相關 → 聯絡人 → 篩選: 全名 = "{聯絡人姓名}"
→ 顯示: 名稱、主日日期、小組名單、週報
```

### 3?? 檢查週報
```
CRM → 進階尋找 → 小組主日週報
→ 篩選: 小組名單 = "{錯誤的小組}"
→ 開啟最近週報 → 相關 → 個人聚會與靈修記錄
→ 查找該聯絡人
```

---

## ?? 快速修復（3 個方案）

### 方案 A: 修正出席記錄 ??
**適用**: 週報中找到該聯絡人的記錄

```
1. 開啟錯誤的出席記錄
2. 修改 "小組名單" → 選擇正確的小組
3. 修改 "週報" → 選擇正確的週報
4. 儲存
```

### 方案 B: 從名單移除 ??
**適用**: 聯絡人在錯誤的名單中

```
1. CRM → 行銷 → 名單 → {錯誤的小組}
2. 成員標籤 → 找到聯絡人
3. 勾選 → 從名單移除
4. 確認
```

### 方案 C: 刪除錯誤記錄 ???
**適用**: 重複或錯誤建立的記錄

```
1. 開啟錯誤的出席記錄
2. 刪除
3. 確認
```

---

## ? 驗證修復（2 分鐘）

```
1. 重新啟動應用程式或清除快取
2. 訪問 /Equipment/EquipmentView
3. 展開錯誤的小組 → 確認聯絡人不在
4. 展開正確的小組 → 確認聯絡人存在
```

## ?? 常見錯誤原因

| 原因 | 可能性 | 解決方案 |
|------|--------|----------|
| 出席記錄小組關聯錯誤 | 90% | 方案 A |
| 聯絡人在多個名單中 | 8% | 方案 B |
| 重複的出席記錄 | 2% | 方案 C |

## ?? FetchXML 快速查詢

**查詢聯絡人的所有出席記錄**:
```xml
<fetch version='1.0'>
  <entity name='new_present_record'>
    <attribute name='new_name' />
    <attribute name='new_sunday_date' />
    <attribute name='new_list_new_present_record' />
    <link-entity name='contact' from='contactid' to='new_contact_new_present_record'>
      <filter>
        <condition attribute='fullname' operator='eq' value='{聯絡人姓名}' />
      </filter>
    </link-entity>
    <link-entity name='list' from='listid' to='new_list_new_present_record' alias='list'>
      <attribute name='listname' />
    </link-entity>
  </entity>
</fetch>
```
