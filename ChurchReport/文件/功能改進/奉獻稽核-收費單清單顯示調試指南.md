## ?? 常見問題排查

### 問題 1: 網格不顯示

**症狀**: 點選連絡人後,奉獻清單區塊沒有出現

**檢查**:
```javascript
// 在 Console 中執行
document.getElementById("data-grid").style.display
// 應該返回: "" (空字串表示顯示)

// 如果返回 "none",手動設置:
document.getElementById("data-grid").style.display = "";
```

**可能原因**:
1. `data.status` 不是 `1`
2. `data.clicktype` 不是 `"查詢"`
3. JavaScript 錯誤導致執行中斷

### 問題 2: 網格顯示但沒有資料

**症狀**: 奉獻清單網格顯示,但裡面是空的

**檢查**:
```javascript
// 在 Console 中執行
var grid = $("#DedicationFeeGrid").dxDataGrid("instance");
var dataSource = grid.getDataSource();
console.log("Items:", dataSource.items());
console.log("Total Count:", dataSource.totalCount());
```

**可能原因**:
1. `m_QpayModel.DedicationFeeList` 是空的
2. `LoadDedicationFeeList` 沒有正確返回數據
3. DataGrid 沒有正確刷新

**解決方案**:
```javascript
// 手動刷新 DataGrid
$("#DedicationFeeGrid").dxDataGrid("instance").refresh();
```

### 問題 3: 數據返回但顯示錯誤

**症狀**: Console 顯示有數據,但 DataGrid 顯示不正確

**檢查**:
1. 檢查日期格式是否正確
2. 檢查 `ParsingDate` 函數是否正常工作
3. 檢查欄位綁定是否正確

**調試代碼**:
```javascript
// 在 Console 中測試日期解析
function ParsingDate(input) {
    var ParsedDate = new Date(input);
    console.log("Input:", input, "Output:", ParsedDate);
    return ParsedDate;
}

// 測試
ParsingDate("2024-01-15T00:00:00");
```

### 問題 4: LoadDedicationFeeList 返回 404

**症狀**: Network 標籤顯示 404 錯誤

**檢查**:
1. Controller 名稱是否正確: `DedicationAudit`
2. Action 名稱是否正確: `LoadDedicationFeeList`
3. 路由是否正確配置

**驗證 Controller**:
```csharp
// 確認 DedicationAuditController.cs 中有此方法
[HttpGet]
public object LoadDedicationFeeList(string id, DataSourceLoadOptions loadOptions)
{
    try
    {
        var tasks = InMemoryContext.QpayManager.m_QpayModel.DedicationFeeList;
        return DataSourceLoader.Load(tasks, loadOptions);
    }
    catch (Exception e)
    {
        return HandleError(e, "LoadDedicationFeeList");
    }
}
```
