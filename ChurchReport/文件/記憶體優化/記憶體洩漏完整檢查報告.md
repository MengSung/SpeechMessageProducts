**修復後** (正確模式):
```csharp
// 靜態 HttpClient 單例
private static readonly Lazy<System.Net.Http.HttpClient> _lazyHttpClient = 
    new Lazy<System.Net.Http.HttpClient>(() =>
    {
        var client = new System.Net.Http.HttpClient();
        client.DefaultRequestHeaders.Add("X-KeyID", X_KEY_ID);
        client.Timeout = TimeSpan.FromSeconds(30);
        return client;
    });

private static System.Net.Http.HttpClient SharedHttpClient => _lazyHttpClient.Value;

private static async Task<NonceRes> GetNonce(NonceReq req)
{
    // ? 重用靜態單例
    responce = await SharedHttpClient.PostAsJsonAsync(url, req);
}
```

### ? 合格模式

#### 模式 1: 完整的 Dispose Pattern
```csharp
public class GoodService : IDisposable
{
    private Timer _timer;
    private bool _disposed;
    
    public GoodService()
    {
        _timer = new Timer(OnTimer, null, 0, 1000);
    }
    
    private void OnTimer(object state) { }
    
    protected virtual void Dispose(bool disposing)
    {
        if (_disposed)
            return;
            
        if (disposing)
        {
            // ? 釋放托管資源
            _timer?.Dispose();
            _timer = null;
        }
        
        _disposed = true;
    }
    
    public void Dispose()
    {
        Dispose(true);
        GC.SuppressFinalize(this);
    }
}
```

#### 模式 2: 事件訂閱正確取消
```csharp
public class GoodManager : IDisposable
{
    private readonly IEventSource _source;
    private bool _disposed;
    
    public GoodManager(IEventSource source)
    {
        _source = source;
        _source.DataChanged += OnDataChanged;
    }
    
    private void OnDataChanged(object sender, EventArgs e) { }
    
    public void Dispose()
    {
        if (_disposed)
            return;
            
        _disposed = true;
        
        // ? 取消事件訂閱
        if (_source != null)
        {
            _source.DataChanged -= OnDataChanged;
        }
    }
}
```

#### 模式 3: 連接正確管理
```csharp
public class GoodConnector
{
    public void ProcessData()
    {
        // ? 使用 using 確保釋放
        using (var connection = new SqlConnection(connectionString))
        {
            connection.Open();
            // 處理數據
        } // 自動釋放連接
    }
    
    // 或使用連接池
    private readonly ICrmConnectionPool _pool;
    
    public void ProcessDataWithPool()
    {
        var connection = _pool.AcquireConnection();
        try
        {
            // 處理數據
        }
        finally
        {
            // ? 確保釋放回連接池
            _pool.ReleaseConnection(connection);
        }
    }
}
```

## ?? 檢查標準

### 必須滿足的條件

1. **IDisposable 實現**
   - [ ] 所有持有非托管資源的類別必須實現 IDisposable
   - [ ] 所有訂閱事件的類別必須實現 IDisposable
   - [ ] 所有使用 Timer 的類別必須實現 IDisposable

2. **事件訂閱**
   - [ ] 每個 `+=` 訂閱都必須有對應的 `-=` 取消訂閱
   - [ ] 取消訂閱必須在 Dispose 方法中執行
   - [ ] 靜態事件訂閱必須特別小心處理

3. **資源釋放**
   - [ ] 所有 IDisposable 資源必須在 Dispose 中釋放
   - [ ] 使用 using 語句或 try-finally 確保釋放
   - [ ] 避免在 Dispose 中拋出異常

4. **連接管理**
   - [ ] 使用連接池而非直接創建連接
   - [ ] 確保連接在使用後釋放回連接池
   - [ ] 實現連接超時和重試機制

5. **記憶體配置**
   - [ ] 大型 byte[] 考慮使用 ArrayPool
   - [ ] 避免不必要的大對象分配
   - [ ] 減少 Gen 2 GC 壓力
