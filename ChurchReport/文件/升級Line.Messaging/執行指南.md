## ?? 升級內容

### 1. 專案檔案變更

#### 變更前 (.NET Standard 1.6)
```xml
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <TargetFramework>netstandard1.6</TargetFramework>
    <LangVersion>7.3</LangVersion>
  </PropertyGroup>
  <ItemGroup>
    <PackageReference Include="Newtonsoft.Json" Version="13.0.3" />
  </ItemGroup>
</Project>
```

#### 變更後 (.NET 10)
```xml
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <TargetFramework>net10.0</TargetFramework>
    <LangVersion>latest</LangVersion>
    <Nullable>enable</Nullable>
    <ImplicitUsings>disable</ImplicitUsings>
  </PropertyGroup>
  <ItemGroup>
    <PackageReference Include="Newtonsoft.Json" Version="13.0.3" />
  </ItemGroup>
</Project>
```

### 2. 主要變更

| 項目 | 舊版本 | 新版本 | 說明 |
|-----|--------|--------|------|
| Target Framework | netstandard1.6 | net10.0 | 升級至最新 .NET |
| C# Language Version | 7.3 | latest | 啟用最新語言功能 |
| Nullable Reference Types | 未啟用 | enable | 提升代碼安全性 |
| Implicit Usings | N/A | disable | 保持現有程式碼風格 |
| Newtonsoft.Json | 13.0.3 | 13.0.3 | 維持版本 |

### 3. 程式碼相容性

? **無需修改程式碼**

Line.Messaging 專案的程式碼已經非常現代化，使用了：
- async/await 模式
- HttpClient 正確使用
- IDisposable 模式
- 完整的 XML 文件註解

所有現有程式碼與 .NET 10 100% 相容，無需任何修改。

## ?? 執行步驟

### 方法 1: 使用 PowerShell 腳本 (推薦)

1. **關閉 Visual Studio**

2. **開啟 PowerShell** (以系統管理員身分執行)

3. **導航至專案根目錄**:
   ```powershell
   cd "D:\網頁APP雲端線上版本\DevExpressDevExtreme-21.2.7版本\音訊產品版本\ChurchReport"
   ```

4. **執行升級腳本**:
   ```powershell
   .\ChurchReport\文件\升級Line.Messaging\升級腳本.ps1
   ```

5. **重新開啟 Visual Studio**

6. **還原 NuGet 套件**:
   - 在 Visual Studio 中，右鍵點擊方案
   - 選擇「還原 NuGet 套件」

7. **重新建置專案**:
   ```
   建置 > 重建方案
   ```

### 方法 2: 手動升級

1. **關閉 Visual Studio**

2. **備份舊專案檔案**:
   ```powershell
   Copy-Item "Line.Messaging\Line.Messaging.csproj" "Line.Messaging\Line.Messaging.csproj.backup"
   ```

3. **替換專案檔案**:
   ```powershell
   Remove-Item "Line.Messaging\Line.Messaging.csproj"
   Copy-Item "Line.Messaging\Line.Messaging_Net10.csproj" "Line.Messaging\Line.Messaging.csproj"
   ```

4. **重新開啟 Visual Studio 並還原套件**
