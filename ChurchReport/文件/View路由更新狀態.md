## 更新方法

### 方法 1: 使用自動化腳本 (推薦)
```powershell
.\Scripts\Update-ViewRoutes.ps1
```

### 方法 2: 手動更新
使用 Visual Studio 的「尋找和取代」功能:
1. 按 `Ctrl+Shift+H`
2. 輸入搜尋模式 (例如: `/Home/MultiGroupView`)
3. 輸入取代模式 (例如: `/SmallGroup/MultiGroupView`)
4. 全部取代

### 方法 3: 批次處理
針對特定控制器的所有路由一次性更新。
