# 逐檔整體說明與永久規範

使用者要求每個檔案具有完整、詳細、深入的檔案註解，清楚說明目的與功能，並永久套用於未來新增與修改。

範圍：目前工作樹自行維護的 C#、Razor、前端程式、建置與維運腳本；設定、專案及不接受註解的格式採安全原生註解或逐檔伴隨說明。第三方、二進位、歷史證據、工作流程自動產生快照不改寫內容，逐項標明來源與用途。產生程式必須修正產生器及重生。

檔頭須以實際內容交代整體目的、入口與合作元件、主要流程／輸入輸出、責任邊界；涉及隔離／資源生命週期者補充實際擁有權與限制，測試補充保護的契約。禁止單純重述檔名、複製不相符的萬用安全保證，或假稱舊程式已實作尚不存在的防護。

驗收：所有納管檔案可逐檔追溯說明；C#／Razor UTF-8無BOM、CRLF及檔尾CRLF；編譯／測試通過；除必要文件驗證工具外既有程式只有註解變動；未提交P1修改保留。永久規範與檢查入口同步完成。
