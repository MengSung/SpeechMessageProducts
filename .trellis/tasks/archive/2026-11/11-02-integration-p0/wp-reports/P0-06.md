## AGENTS.md 檢查
- PowerShell 函數及測試區塊以繁中註解說明信任邊界、拒絕條件與資源 owner；所有可執行 token 都是 ASCII，非 ASCII 只在註解。
- 來源單檔十六 MiB 上限，文字只在當檔處理期間保留；集合只保留位置／雜湊／型別。沒有外部程序、背景工作、watcher、連線、使用者或教會狀態。
- UTF-8 嚴格讀取，既有 CP950 僅唯讀嚴格解碼，來源完全不改寫；編碼合法性仍由專用 Changed 守門負責。
- 方案、專案、基準與來源均檢查根邊界；不向上找父 worktree、不沿 reparse point；排除 bin／obj／docs／.ccg／.worktrees／參考舊方案及產生檔。
- JSON 基準拒絕重複群組或位置，避免字典覆寫造成假通過；報告不含來源本文或機密。
- 沒有新增產品例外流程或 LINE 通知出口，工具以固定失敗類別及非零結束碼回報。
