# 線 A／線 B 進度圖解調查

## 目標與使用者價值
以最新 Codex 線程、即時狀態、1.3 計畫進度與各工作樹狀態為依據，向使用者清楚說明線 A、線 B 目前做到哪裡、正在做什麼、阻礙與風險，並交付可離線開啟的繁體中文 HTML 圖解。

## 已確認需求
- 來源為目前活躍的「三大產品共通層」線 A 與線 B Codex threads。
- 需要判斷是否遇到困難、是否偏離計畫或有錯誤，以及當下正在進行的具體工作。
- 交付一個自包含 `.html` 檔，優先以泳道圖、時間線、依賴關係與證據標示解釋現況。
- 重要結論須區分直接證據、推論與尚未驗證項目；離線驗證不得描述為實機完成。

## 驗收標準
1. 報告標註擷取時間（Asia/Taipei）及來源邊界。
2. A、B 各自包含目前工作包、已完成／未完成內容、正在做的工作、阻礙與風險。
3. 對實際工作樹、整合分支、狀態檔與即時進度間的重要差異明確註記。
4. 以清楚的原創 SVG／HTML 圖解表達雙線並行與依賴，不依賴外部網路資源。
5. 交付 HTML 並檢查檔案存在、UTF-8 可讀、主要圖解與關鍵文字均在文件中。

## 範圍外
- 不修改線 A、線 B 的程式碼、分支、鎖、VM、D365、SQL、LINE 或付款沙箱。
- 不代替任何線程執行、取消或變更其工作。
- 不將歷史命令錯誤等同於產品缺陷；只在證據支持時判定偏差或錯誤。
