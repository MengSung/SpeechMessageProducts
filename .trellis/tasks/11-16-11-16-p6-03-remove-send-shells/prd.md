# P6-03 移除送訊相容殼

## Goal

依 06A §4.1、§4.2、§5 P6-03 移除 ChurchReport 與 ToolUtility 送訊相容殼，保留 legacy 工作流程、錯誤政策、訊息內容與資源 owner；完成指定黃金、通知器及移除測試。

## Requirements

- ChurchReport 正式呼叫路徑維持 `ILineNotificationWorkflow`／`LineLegacySendWorkflow`，不得改走 `LineMessagingProcessor.Core`。
- 只透過暫時改名後的建置錯誤盤點四個相容殼的正式與測試呼叫者；反射／DI 使用另依 06A 清單核對。
- 以 `ChurchReportLineNotifier` 集中四種仍有正式呼叫者的通知入口，保留原本文字、來源代號、RetryKey、等待方式、失敗政策與 client owner。
- P2-06 黃金檔保持原始位元組與 SHA-256；每個案例必須明確標記為重播或有理由退役。
- 移除四個指定送訊相容殼及只測這些相容殼的測試；仍保護共用流程契約的案例不得丟失。
- 不改 `duplicate-baseline.json`、NoWarn、部署設定、D365 步驟／流程或 06A；不新增專案。
