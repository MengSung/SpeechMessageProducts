## ?? Phase 2: 事件訂閱洩漏修復 (P1) ? 已完成審計

### 2.1 問題說明

事件訂閱 (`+=`) 如果沒有對應的取消訂閱 (`-=`)，會導致：
- 訂閱者物件無法被 GC 回收
- 發布者持有訂閱者的強參考
- 長時間運行後記憶體持續增長

### 2.2 ? 審計結果

經過完整掃描，本專案**沒有使用傳統的 C# 事件訂閱模式**（`event EventHandler`）。

專案使用的是：
- **依賴注入模式**：透過建構函式注入 `LineMessagingClient`
- **虛擬方法模式**（Template Method Pattern）：如 `WebhookApplication.cs`
- **非同步方法**：直接呼叫 async/await 方法

### 2.3 ? 已修復項目

#### 2.3.1 ChurchReport\Tools\LineUtilityClass.cs
- ? 修正 `Dispose()` 方法，確保 `LineMessagingClient` 被正確釋放

| `WebhookApplication` | ? 正確 | 使用虛擬方法模式，無事件訂閱 |

### 2.5 審計結論

原始審計報告中提到的「434 處事件訂閱」實際上是 `+=` 數值累加運算（如 `count += 1`），而非事件訂閱。本專案**不存在傳統的事件訂閱洩漏問題**。

### 4.3 ? 已修復項目

#### 4.3.1 ChurchReport\Models\ContextDictionary.cs

**問題**：原始實現使用普通 `Dictionary`，沒有清理機制，會持續增長導致記憶體洩漏。

**修復內容**：
- ? 改用 `ConcurrentDictionary` 確保執行緒安全
- ? 增加自動清理計時器（每 5 分鐘清理一次）
- ? 設定過期時間（30 分鐘未存取即過期）
- ? 設定最大項目數限制（1000 個）
- ? 增加 LRU 清理機制（超過限制時清理最舊項目）
- ? 釋放過期項目時正確 Dispose 資源

```csharp
public static class ContextDictionary 
{
    // ? 使用 ConcurrentDictionary 確保執行緒安全
    private static readonly ConcurrentDictionary<string, ContextEntry> _contextDictionary 
        = new ConcurrentDictionary<string, ContextEntry>();
    
    // ? 清理計時器
    private static readonly Timer _cleanupTimer;
    
    // ? 過期時間（30 分鐘未存取即過期）
    private static readonly TimeSpan _expirationTime = TimeSpan.FromMinutes(30);
    
    // ? 清理間隔（每 5 分鐘清理一次）
    private static readonly TimeSpan _cleanupInterval = TimeSpan.FromMinutes(5);
    
    // ? 最大項目數限制
    private const int MaxItems = 1000;

    static ContextDictionary()
    {
        _cleanupTimer = new Timer(CleanupExpiredEntries, null, _cleanupInterval, _cleanupInterval);
    }

    private static void CleanupExpiredEntries(object state)
    {
        var now = DateTime.UtcNow;
        var keysToRemove = _contextDictionary
            .Where(kvp => (now - kvp.Value.LastAccessTime) > _expirationTime)
            .Select(kvp => kvp.Key)
            .ToList();

        foreach (var key in keysToRemove)
        {
            if (_contextDictionary.TryRemove(key, out var removed))
            {
                // ? 釋放資源
                (removed.Context as IDisposable)?.Dispose();
            }
        }
    }
}
```

| 執行緒安全 | ? 不安全 | ? 安全 |
| 過期清理 | ? 無 | ? 自動清理 |
| 最大項目數 | ? 無限制 | ? 1000 個 |
| 資源釋放 | ? 無 | ? 正確 Dispose |
