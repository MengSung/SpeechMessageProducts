## ?? 程式碼修改

### 位置: `DownloadIntegrateData.cs`

### 修改內容: 

在 `GetAllMemberDataFromPresentRecord` 方法中添加小組關聯驗證：

```csharp
#region ? 新增：驗證出席記錄的小組關聯
// 確保出席記錄的小組名單與當前小組一致，避免聯絡人顯示在錯誤的小組中
Guid presentRecordListId = this.m_ToolUtilityClass.GetEntityLookupAttribute(
    PresentRecordEntity, "new_list_new_present_record");
Guid currentListId = this.m_ListEntity.Id;

if (presentRecordListId != Guid.Empty && presentRecordListId != currentListId)
{
    // 記錄詳細的診斷資訊
    System.Diagnostics.Debug.WriteLine($"[資料驗證警告] 偵測到小組關聯不一致");
    System.Diagnostics.Debug.WriteLine($"  聯絡人: {FullName} (ContactId: {ContactId})");
    System.Diagnostics.Debug.WriteLine($"  當前小組: {GroupName} (ListId: {currentListId})");
    System.Diagnostics.Debug.WriteLine($"  出席記錄的小組ID: {presentRecordListId}");
    System.Diagnostics.Debug.WriteLine($"  出席記錄ID: {PresentRecordEntity.Id}");
    
    try
    {
        DateTime sundayDate = this.m_ToolUtilityClass.GetEntityDateTimeAttribute(
            PresentRecordEntity, "new_sunday_date");
        System.Diagnostics.Debug.WriteLine($"  主日日期: {sundayDate.ToShortDateString()}");
    }
    catch { }
    
    System.Diagnostics.Debug.WriteLine($"  動作: 跳過此記錄，避免顯示在錯誤的小組中");
    System.Diagnostics.Debug.WriteLine($"  建議: 在 CRM 中修正此出席記錄的小組名單欄位");
    
    // 跳過此記錄，避免顯示在錯誤的小組中
    continue;
}
#endregion
```

### 插入位置:
- 在取得聯絡人姓名和 ContactId 之後
- 在開始處理聯絡人詳細資料之前
- 具體位置：`GetAllMemberDataFromPresentRecord` 方法中，緊接在 `#endregion// 出席紀錄組員的全名` 之後

## ?? CRM 操作速查

### 查詢名單成員
```
CRM → 進階尋找 → 名單 → 新增相關 → 名單成員 → 新增相關 → 聯絡人
→ 篩選: 全名 = "{姓名}"
```

### 查詢出席記錄
```
CRM → 進階尋找 → 個人聚會與靈修記錄 → 新增相關 → 聯絡人
→ 篩選: 全名 = "{姓名}"
→ 顯示: 名稱、主日日期、小組名單、週報
```

### 修正出席記錄
```
開啟記錄 → 修改 "小組名單" → 修改 "週報" → 儲存
```

### 從名單移除
```
CRM → 行銷 → 名單 → {小組} → 成員 → 勾選 → 從名單移除
```
