### C. C# 7.3 語法限制 (2處)
不能使用 switch expression，需改用 switch statement:

```csharp
// C# 8.0+ (不支援)
return id switch
{
    "區牧" => "race_id",
    "牧區" => "new_pastoralarea",
    "小組" => "new_smallgroup",
    _ => null
};

// C# 7.3 (支援)
switch (id)
{
    case "區牧":
        return "race_id";
    case "牧區":
        return "new_pastoralarea";
    case "小組":
        return "new_smallgroup";
    default:
        return null;
}
```

**受影響的檔案:**
- [ ] ListManagementController.cs (2處，同一個方法)

### D. ref 參數問題 (2處)
`readonly` 欄位不能當作 `ref` 參數傳遞:

```csharp
// 問題
.SavePersonalReportForm(ref ToolUtility, viewModel);

// 解決方案 1: 移除 ref (推薦)
.SavePersonalReportForm(ToolUtility, viewModel);

// 解決方案 2: 修改方法簽章，不要求 ref
public void SavePersonalReportForm(ToolUtilityClass toolUtility, ViewModel vm)
```

**受影響的檔案:**
