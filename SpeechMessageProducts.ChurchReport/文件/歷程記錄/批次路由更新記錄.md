### ?? 更新方法建議

#### 方法 1: 使用 Visual Studio 的「尋找和取代」
1. 開啟 Visual Studio
2. 按 `Ctrl+Shift+H` 開啟「在檔案中取代」
3. 設定搜尋範圍: `*.cshtml`
4. 使用正規表示式搜尋並取代

#### 方法 2: 使用 VS Code 的多檔案取代
1. 開啟 VS Code
2. 按 `Ctrl+Shift+F` 開啟全域搜尋
3. 啟用正規表示式模式
4. 逐一確認並取代

#### 方法 3: 逐一檔案手動更新
1. 依照上面的清單順序
2. 開啟每個檔案
3. 使用 `Ctrl+F` 搜尋 `/Home/`
4. 手動更新為對應的新控制器
