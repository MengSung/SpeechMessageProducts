# 奉獻稽核 - 同名連絡人選擇後顯示奉獻清單功能

## ?? 需求說明

當奉獻稽核查詢時找到多筆同名同姓的連絡人 (`DedicationContacts.Entities.Count > 1`)，用戶在 `SameNameList` 中點選其中一筆後，應該像 `KeyInDedicationFeeViewWeb` 一樣自動顯示該連絡人的奉獻清單。

## ?? 實施目標

1. 當查詢結果有多筆連絡人時，顯示 `SameNameList` 表格供用戶選擇
2. 用戶點選表格中的某一筆連絡人後，自動觸發查詢該連絡人的奉獻記錄
3. 顯示選中連絡人的奉獻清單和總金額

## ?? 實施內容

#### 修改後
```javascript
function OnRowClick(selectedItems) {
    var data = selectedItems.selectedRowsData[0];
    if (data) {
        $("#form").dxForm("instance").updateData('DedicationNumber', data.DedicationNumber);
        $("#form").dxForm("instance").updateData('NationId', data.NationId);
        $("#form").dxForm("instance").updateData('FullName', data.FullName);
        $("#form").dxForm("instance").updateData('Mobile', data.Mobile);
        $("#SameNameList").dxDataGrid("instance").deselectAll();

        // 自動觸發查詢該連絡人的奉獻清單
        setTimeout(function() {
            $("#form").dxForm("instance").getEditor("ClickType").option("value", '查詢');
            getLoadPanelInstance().show();
            $("form").submit();
        }, 300);
    }
}
```

同樣的修改也應用到 `OnRowSelectionChanged` 函數。

### 2. 關鍵修改點

```csharp
public async Task<IActionResult> AuditQueryDedication(QpayModel QpayModel)
{
    // ...查詢邏輯...
    
    if (DedicationContacts.Entities.Count == 1)
    {
        // 單筆結果 - 載入奉獻清單
        SetDedicationFeeList(DedicationContacts.Entities[0]);
        String TotalAmount = "總金額 = " + m_QpayModel.TotalAmount + "元";
        
        return Json(new { 
            status = "1", 
            clicktype = "查詢", 
            DedicationNumber, 
            NationId, 
            FullName, 
            Mobile, 
            LastSixDigit, 
            TotalAmount, 
            message = DedicationResult, 
            DedicationResult 
        });
    }
    else if (DedicationContacts.Entities.Count > 1)
    {
        // 多筆結果 - 顯示選擇清單
        m_QpayModel.SameNameList.Clear();
        // ...填充 SameNameList...
        
        return Json(new { 
            status = "2", 
            clicktype = "查詢", 
            DedicationNumber = "", 
            NationId = NationId, 
            FullName = "", 
            Mobile = "", 
            message = "", 
            DedicationResult = "" 
        });
    }
    // ...其他情況處理...
}
```

## ?? 執行流程圖

```
用戶查詢
    ↓

    ↓
顯示 SameNameList 表格
    ↓
用戶點選其中一筆
    ↓
OnRowClick / OnRowSelectionChanged
    ↓
填入表單欄位
    ↓
自動提交表單 (300ms 延遲)
    ↓

    ↓
單筆結果 (status=1)
    ↓
SetDedicationFeeList 載入奉獻清單
    ↓
返回奉獻資料
    ↓
前端顯示:
  - 隱藏 SameNameList
  - 顯示 DedicationFeeGrid
  - 顯示總金額
```

### 設計考量
1. **300ms 延遲**: 給予足夠時間讓 DevExtreme Form 完成數據綁定
2. **自動提交**: 提供更好的用戶體驗,減少點擊操作
3. **Loading 反饋**: 讓用戶清楚知道系統正在處理
