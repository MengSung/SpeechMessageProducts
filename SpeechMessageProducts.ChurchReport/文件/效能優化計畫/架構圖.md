```
            │               │               │

    ┌─────────────┐ ┌─────────────┐ ┌─────────────┐

    └─────────────┘ └─────────────┘ └─────────────┘
            │               │               │

    QueryAsync()      Task.WhenAll()   async Task<>
    CreateAsync()     Parallel.ForEach  await
    UpdateAsync()     Batch(50-100)     ConfigureAwait

```

### 批量操作對比

```
? 同步逐一處理 (慢)
┌────────────────────────────────────────┐
│ foreach (member in members)            │
│ {                                      │
│     AddToList(member);  // 阻塞等待     │
│ }                                      │
└────────────────────────────────────────┘
Time: 100ms × 100 = 10,000ms (10秒)


? 並行批量處理 (快)
┌────────────────────────────────────────┐
│ await Task.WhenAll(                    │
│     members.Select(m =>                │
│         AddToListAsync(m)              │
│     )                                  │
│ );                                     │
└────────────────────────────────────────┘
Time: ~1,000ms (1秒) - 快10倍！
```

### Strategy Pattern 架構

```
┌─────────────────────────────────────────────────────┐
│          QueryStrategySelector                      │
│          (自動選擇最佳策略)                           │
└───────────────────┬─────────────────────────────────┘
                    │ Evaluates
        ┌───────────┼───────────┐
        │           │           │
        ▼           ▼           ▼
┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│  FetchXML    │ │QueryExpression│ │    LINQ      │
│  Strategy    │ │   Strategy   │ │  Strategy    │
└──────────────┘ └──────────────┘ └──────────────┘
     Score: 70       Score: 80        Score: 90
        │               │               │
        └───────────────┴───────────────┘
                        │
                        ▼
            自動選擇最高分策略執行

適用場景:
- FetchXML    ? 複雜查詢、聚合

- LINQ        ? 強型別、記憶體內

優點: 查詢效能 ↑25%
```
