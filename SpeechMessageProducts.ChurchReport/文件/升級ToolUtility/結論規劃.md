# 結論與可執行升級規劃：ToolUtility → .NET 10

此文件基於先前兩份規劃文件之比較與批判結果，整理出可直接執行的升級結論、優先級與每步驟的驗收標準（acceptance criteria）。目標：小步、安全、可回滾地將 `ToolUtility` 從 .NET Framework 4.6.2 遷移到 .NET 10，同時修正現有高風險點並加入自動化驗證。

---

一、核心結論（簡明）
- 採用小 PR 流程,每個 PR 單一目的、含測試與性能基線。每個 PR 必須通過 CI（build + 單元測試 + resource leak checks + perf smoke）。
- 優先處理安全與資源洩漏問題（FileStream/TraceListener/硬編碼密碼/OrganizationServiceProxy）。
- 引入 `ICrmClient` Adapter 與 `IToolUtility` Facade，讓舊呼叫逐步遷移，保持向後相容。
- 在升級期間以 multi-target（net462;net10.0）策略降低中斷風險（視相依套件情況）。

---

二、不可跳過的高風險修正（必做）
1. ctor/全局資源釋放
   - 立即移除或重構 `ToolUtilityClass` 中在建構式中打開的 `FileStream`/`StreamWriter`/TraceListener；改以 `ILogger` 注入或在需要時開啟與 `using`。
   - 驗收：靜態檢查無長期 FileStream 實例；單元測試模擬啟動/關閉，不留句柄。
2. 移除硬編碼憑證/路徑/encoding
   - 把 USERNAME/PASSWORD/DOMAIN、`D:\...` 路徑、`Encoding.GetEncoding("big5")` 改為可配置（IConfiguration / secrets / env）。
   - 驗收：所有機密來源由配置驅動；敏感字串不出現在 repo。
3. OrganizationServiceProxy → Adapter
   - 新增 `ICrmClient` + `DataverseAdapter`；短期保留 `LegacyAdapter` 作為回滾選項。
   - 驗收：所有直接 `OrganizationServiceProxy` 呼叫被封裝並有 unit-tests mock。

---

四、CI Gate 與自動化驗收（每 PR 必須通過）
- Build (net10.0, 並視情況測試 net462)
- Unit tests (coverage baseline for modified code)
- Static analyzers: Roslyn CA2000、FxCop、SecurityScanner
- Resource leak detection: run a short smoke that starts/stops key services and ensures no open file handles (scriptable check)
- Perf smoke: compare response time / memory snapshot vs baseline for key scenarios (threshold configurable, e.g. 15% allowable)

---

五、記憶體/資源洩漏檢測與工具
- 必用：dotnet-trace、dotnet-dump、dotnet-gcdump、BenchmarkDotNet（micro benchmark）。
- 在 CI：每個 PR 的 smoke stage 收集短期 memory snapshot，比對差異；若發現 growth anomaly，阻止合併。

---

六、遵守 Linus 原則（落地化規則）
- 每個 commit / PR 小而單一：PR 不做超過一項語義變更。
- 可回滾：每個 PR 可獨立 revert，CI 保證可回滾前的穩定狀態。
- 以事實為準：所有假設要有測試或基準佐證，不做未測試的大重構。

---

七、設計模式應用（快速參考）
- Adapter（外部 CRM 介面切換）
- Facade（對外暴露簡潔 API）
- Repository（資料存取分層）
- Decorator（logging/retry）
- Factory（根據配置產生 Adapter）
- **Service Layer**（業務邏輯分層，詳見 [PR4_CLASS_REBUILD.md](./PR4_CLASS_REBUILD.md)）
- **Composite**（屬性服務組合，詳見 [PR4_CLASS_REBUILD.md](./PR4_CLASS_REBUILD.md)）
