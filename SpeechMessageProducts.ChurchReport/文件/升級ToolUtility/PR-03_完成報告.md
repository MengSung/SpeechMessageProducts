## ?? 設計模式應用驗證

### Adapter Pattern ?
- **目的**：隔離 `OrganizationServiceProxy` 與 `ServiceClient` 差異
- **實作**：`ICrmClient` 介面 + 2 個 Adapter
- **驗證**：上層程式碼只需依賴 `ICrmClient`，不需知道底層實作

### Factory Method Pattern ?
- **目的**：根據配置建立正確的 Adapter
- **實作**：`CrmClientFactory.Create(IConfiguration)`
- **驗證**：可透過 `appsettings.json` 切換 Adapter

### Dependency Injection Ready ?
- **設計**：所有 Adapter 實作 `ICrmClient` 介面
- **用法**：可在 `Startup.cs` 註冊為 Scoped service
- **範例**：
  ```csharp
  services.AddScoped<ICrmClient>(sp => 
      CrmClientFactory.Create(sp.GetRequiredService<IConfiguration>())
  );
  ```
