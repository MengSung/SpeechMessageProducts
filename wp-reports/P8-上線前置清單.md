# P8 上線前置清單

本清單只供使用者日後核定好牧人 9.1 正式上線作業，本階段不執行、不連正式組織。

1. 每個正式組織依 `驗收\P7_組織切換手冊.md` 與 07A §6C 順序，先備份並確認回復路徑。
2. 先做結構 apply（含本階段兩個查閱欄），開啟組織稽核，再執行 `migrate-offering-categories`：plan → 使用者核定 → apply → verify；每間教會「有選項值沒有查閱值」必須為 0，跨教會 lookup 必須為 0。備份保存檔案雜湊；同一份 plan 第二次 apply 的 lookup 更新批次必須為 0。
3. 類別轉換與回填完成前，不部署新版 ChurchReport；若教會沒有正式類別，新增奉獻必須先 fail-closed。完成後核對清單與舊畫面行為；類別代碼使用 `legacy-<值>`，名稱使用 new_fee 語系 1028 標籤。
4. ChurchReport／LineWebhook 部署本分支版本，逐項核對 `Localization:ChurchOverrides:Enabled`、`Messaging:NotifyRelay:Enabled` 等部署開關。
5. 執行 `church-defaults` 並保存唯讀結果；若仍有候選但無法重現，依 P8-decisions 的「目前證據不足」結論處理。
6. 依 registration 清單只切換有 Live evidence 的項目；七個 Workflow 活動目前維持 dormant，是否補做由使用者決定。
7. P8-PROP-001／002／003／004／005／006／007／008 逐項核定；偽語系替代證據不得直接推論為正式組織驗收。
8. 每組織完成後 verify=0、狀態 off、SMV-TEST／待辦／測試資料殘留 0；失敗依手冊回復。
9. 上線觀察期至少一週，並完成舊 DLL 移除、語系驗證、回復演練與稽核紀錄。


10. P8-PROP-008 所列 05／00／附錄文字差異留到 3.6 一次處理；本清單不改寫計畫正文。
