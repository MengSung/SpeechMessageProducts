# P8 上線前置清單

2026-11-20 15:34 Asia/Taipei (UTC+08:00)

本清單只供未來 D365 9.1 上線作業使用；本階段不連正式組織，也不執行以下作業。

1. 每個正式組織依 `驗收\P7_組織切換手冊.md` 與 07A §6C 的核准順序進行。
2. 先完成奉獻類別資料轉換及必要 lookup 回填，再部署新版 ChurchReport。不得在教會沒有奉獻類別資料時部署後直接啟用新增奉獻流程。
3. P8-01c 的 lookup 結構已在 goodshepherdback 測試組織驗證；正式組織仍須按計畫執行結構 plan/apply/verify、組織稽核確認、`migrate-offering-categories` plan、逐段核對、核准後 apply、`--verify`，再以同一 plan apply 證明零寫入。
4. 解決並核定 `P8-PROP-008` 中同一 option value 對應多個 metadata labels 與固定類別代碼的規格矛盾；在此之前不可猜標籤、合併類別或執行資料轉換。
5. 部署 ChurchReport 與 LineWebhook 時，依終點回報核定 `Localization:ChurchOverrides:Enabled`、`Messaging:NotifyRelay:Enabled` 等設定。
6. 依 `church-defaults` 流程補齊教會預設值。
7. 註冊清單只切換 `tier=live` 且已有實機證據的項目；按回復手冊逐步執行與核對。
8. 上線前處理終點回報列出的必要提案，並依對應手冊執行回復演練。
