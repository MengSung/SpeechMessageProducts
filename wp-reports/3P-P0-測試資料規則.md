# P0-6 測試資料與個資規則（核定版）

記錄時間：2026-11-25 22:35 Asia/Taipei (UTC+08:00)<br>
適用範圍：三大產品共通層 1.3、所有自動測試與 `Live3P` 測試。<br>
依據：`AGENTS.md`、計畫 00 §2、§5、01「開工前置（P0）」。

## 資料邊界

- `goodshepherd20` 是由 `goodshepherdback` 複製而來，在 G5-2 前仍含真實會友資料。測試環境中的業務操作、身分驗證與推播只可使用測試工具建立、且 `new_istesttenant＝是` 的測試租戶；不得把複製來的會友或其 LINE 身分當成測試資料。
- 上線前推播安全開關固定為 `PushSafety:TestTenantsOnly＝true`。測試標記只能由伺服器端測試工具設定，不能接受呼叫端自行宣稱租戶為測試租戶。發送前須驗證整批目標均屬已驗證的測試租戶；任一目標不符或無法確認時，整批拒絕，不得改用 broadcast 或部分放行。
- 推播只可使用計畫指定的測試 Channel（好牧人池 T01、T02；好管家測試 Channel）。不得使用正式 Channel、未核准 Channel 或好學會 Channel；好牧人官方帳號在本階段僅登錄、不配發。
- `construction` 與 `association` 只建立合成資料，不匯入真實人員、聯絡方式或其他個資。
- 測試記錄須使用權威資料庫 ID 區分；不同 ID 即使顯示內容相同仍各自保留，同一消費集合遇到重複 ID 必須拒絕發布並留下可診斷結果，不得依姓名、電話或其他顯示欄位合併、覆蓋或隱藏。

## 個資與憑證

- 截圖對外或納入報告前，遮蔽姓名、手機號碼及其他可識別資料；LINE userId 不得進入畫面證據、一般日誌、測試輸出或報告。
- 日誌只記足以診斷流程的非敏感識別資訊；不得記錄姓名、電話、LINE userId、token、密碼、金鑰、Cookie、完整請求／回應本文或未驗證個資。
- User Secrets 與部署憑證只由指定安全設定來源讀取；不得複製到 repo、命令輸出、分析提示或工作報告。

## 測試資料生命週期

- 線 B 只建立及清理計畫分配的合成識別碼：教會 `c201–c299`、建設公司 `b201–b299`。清理前先核對產品、租戶及穩定 ID；不得以名稱或電話作為刪除條件，也不得清除其他線或既有資料。
- 測試建立的資料、暫存檔、連線與背景工作由建立它的測試／工作包負責清理；成功、失敗、取消及逾時路徑都須回到預先記錄的資料與資源基線。
- 實機測試使用 `Category=Live3P`，並限於測試組織、測試 Channel、合成資料及測試租戶。若測試租戶標記、租戶範圍或目標環境不能確認，採 fail closed。

本頁只定義核定的資料與個資政策，不代表推播防護已在程式中實作，也不代表任何實機測試已通過。各工作包須以其自動測試及 `Live3P` 證據分別記錄實際執行結果；尚未執行的一律標示「實機待補」。
