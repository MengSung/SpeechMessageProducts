## ?? 快速註解範本

### AudioMessage.cs 註解要點

```xml
<summary>表示 LINE 音訊訊息 / Represents a LINE audio message</summary>
<remarks>
- 格式：M4A
- 最大長度：1 分鐘
- 最大檔案：200MB
- HTTPS 協定
</remarks>
```

### StickerMessage.cs 註解要點

```xml
<summary>表示 LINE 貼圖訊息 / Represents a LINE sticker message</summary>
<remarks>
- 使用 LINE 官方貼圖
- 需要 packageId 和 stickerId
- 可從貼圖清單查詢：https://developers.line.biz/en/docs/messaging-api/sticker-list/
</remarks>
```

### LocationMessage.cs 註解要點

```xml
<summary>表示 LINE 位置訊息 / Represents a LINE location message</summary>
<remarks>
- 包含標題、地址、經緯度
- 可在 LINE 中開啟地圖
- 支援導航功能
</remarks>
```

## ?? 效率提升技巧

### 1. 使用 Visual Studio 範本
建立程式碼片段（Code Snippet）加速註解生成。

### 2. 批次處理相似檔案
一次處理同類型的檔案（如所有動作類別），可以重複使用類似的註解結構。

### 3. 使用 AI 輔助
利用 GitHub Copilot 或其他 AI 工具輔助生成註解。

### 4. 先處理高頻使用檔案
優先完成最常用的類別，確保核心功能有完整文件。

### 5. 定期提交
每完成一個階段就提交一次，避免遺失進度。

## ?? 注意事項

1. **保持一致性**：所有註解使用相同的格式和術語
2. **中英對照**：確保所有註解都有中英文版本
3. **參考官方文件**：註解內容應與 LINE 官方文件一致
4. **測試 IntelliSense**：定期測試註解在 Visual Studio 中的顯示效果
5. **避免過度詳細**：註解應該簡潔明瞭，不需要重複顯而易見的資訊
