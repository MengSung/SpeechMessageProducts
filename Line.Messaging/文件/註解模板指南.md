## ?? 特殊標籤使用指南

### `<remarks>` - 詳細說明

用於提供比 `<summary>` 更詳細的資訊：
- API 的使用限制
- 版本相容性
- 最佳實踐建議
- 相關的官方文件連結

```csharp
/// <remarks>
/// 此方法僅支援 LINE iOS 10.3.0 及 Android 10.3.0 以上版本。
/// <para>
/// This method is only supported on LINE iOS 10.3.0 and Android 10.3.0 or later.
/// </para>
/// <para>
/// 官方文件：https://developers.line.biz/en/reference/messaging-api/
/// Official documentation: https://developers.line.biz/en/reference/messaging-api/
/// </para>
/// </remarks>
```

### `<example>` - 使用範例

提供實際的程式碼範例：

```csharp
/// <example>
/// 以下範例示範如何傳送文字訊息：
/// <code>
/// var client = new LineMessagingClient(channelAccessToken);
/// await client.ReplyMessageAsync(replyToken, new TextMessage("Hello, LINE!"));
/// </code>
/// </example>
```

### `<seealso>` - 相關參照

連結到相關的類別、方法或屬性：

```csharp
/// <seealso cref="TextMessage"/>
/// <seealso cref="ImageMessage"/>
/// <seealso cref="ReplyMessageAsync(string, IList{ISendMessage})"/>
```

### `<exception>` - 例外情況

說明可能拋出的例外：

```csharp
/// <exception cref="ArgumentNullException">
/// 當 replyToken 或 messages 為 null 時拋出
/// Thrown when replyToken or messages is null
/// </exception>
/// <exception cref="LineResponseException">
/// 當 LINE API 回傳錯誤時拋出
/// Thrown when LINE API returns an error
/// </exception>
```

重點：
- 說明訊息類型的用途

- 提供事件處理範例

範例檔案：

## ?? 風格指南

### 中英文註解原則

1. **簡短描述**：中文在前，英文在後，用換行分隔
2. **詳細說明**：使用 `<para>` 標籤區分中英文段落
3. **專有名詞**：保持原文（如 LINE、Flex、Webhook）
4. **技術術語**：提供中英對照（如「訊息/Message」）

### 範例

```csharp
/// <summary>
/// 傳送回覆訊息至 LINE 平台
/// Sends a reply message to LINE platform
/// </summary>
/// <param name="replyToken">
/// 回覆 Token，從 Webhook 事件中取得
/// Reply token obtained from webhook event
/// </param>
/// <param name="messages">
/// 要傳送的訊息清單（最多 5 則）
/// List of messages to send (maximum 5)
/// </param>
/// <returns>
/// 表示非同步作業的工作
/// A task that represents the asynchronous operation
/// </returns>
/// <exception cref="ArgumentNullException">
/// 當 replyToken 或 messages 為 null 時拋出
/// Thrown when replyToken or messages is null
/// </exception>
/// <exception cref="LineResponseException">
/// 當 LINE API 回傳錯誤時拋出（如無效的 Reply Token、訊息數量超過限制等）
/// Thrown when LINE API returns an error (e.g., invalid reply token, message count exceeds limit)
/// </exception>
/// <remarks>
/// Reply Token 只能使用一次，且必須在收到 Webhook 事件後的一段時間內使用（通常為 30 秒）。
/// 超過時間限制後，Reply Token 將失效。
/// <para>
/// Reply token can only be used once and must be used within a certain time after receiving the webhook event (typically 30 seconds).
/// After the time limit, the reply token becomes invalid.
/// </para>
/// <para>
/// 官方文件：https://developers.line.biz/en/reference/messaging-api/#send-reply-message
/// Official documentation: https://developers.line.biz/en/reference/messaging-api/#send-reply-message
/// </para>
/// </remarks>
/// <example>
/// 以下範例示範如何回覆文字訊息：
/// <code>
/// var client = new LineMessagingClient(channelAccessToken);
/// await client.ReplyMessageAsync(
///     replyToken, 
///     new List&lt;ISendMessage&gt;

///         new TextMessage("感謝您的訊息！") 
///     }
/// );
/// </code>
/// </example>
/// <seealso cref="PushMessageAsync(string, IList{ISendMessage})"/>
/// <seealso cref="MultiCastMessageAsync(IList{string}, IList{ISendMessage})"/>
```

## ?? 快速開始

### 步驟 1：選擇檔案類別

根據您的需求，從以下類別中選擇要加註解的檔案：

1. **核心類別** - LineMessagingClient, ILineMessagingClient
2. **基礎訊息** - TextMessage, ImageMessage, VideoMessage, AudioMessage
3. **進階訊息** - FlexMessage, TemplateMessage, ImagemapMessage
4. **Webhook 事件** - MessageEvent, FollowEvent, PostbackEvent
5. **LINE 物件** - UserProfile, BotInfo, GroupSummary
6. **模板與動作** - Template/*, Action/*
7. **Flex 元件** - Flex/Component/*, Flex/Style/*
8. **輔助類別** - Exceptions/*, Json/*, Liff/*

### 步驟 2：套用模板

參考上述模板，為選定的檔案加入註解。

### 步驟 3：驗證註解

使用以下方式驗證註解：

1. **Visual Studio IntelliSense** - 確認註解在 IDE 中正確顯示
2. **XML 文件產生** - 確認專案可以正確產生 XML 文件
3. **DocFX 或 Sandcastle** - 使用文件產生工具建立 API 文件
