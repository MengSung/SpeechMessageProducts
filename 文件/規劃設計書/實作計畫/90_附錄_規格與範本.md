### A.5　Channel Token 加密封包

```
v1:{base64(iv 16 bytes)}:{base64(ciphertext)}:{base64(mac 32 bytes)}
```

- **金鑰：** 64 bytes 隨機值，以 base64 保存。前 32 bytes 是 AES-256 金鑰，後 32 bytes 是 HMAC-SHA256 金鑰。
- **加密：** AES-256-CBC、PKCS7，每次產生新的隨機 IV（`RandomNumberGenerator`）。
- **MAC 計算：** `HMAC-SHA256(macKey, ASCII("v1") || iv || ciphertext)`。
- **解密順序：** 先驗 MAC（固定時間比較），通過才解密。
- **固定時間比較：** net10 用 `CryptographicOperations.FixedTimeEquals`；net48 自行實作「逐位元組 XOR 累加、長度不同也跑完」。兩個目標共用同一組測試向量。
- **金鑰輪替：** 封包版本號保留給未來的 `v2`。輪替時以工具重新加密全部 Channel。

## 附錄 E　I18nCheck 與禁用 API

### E.1　`BannedSymbols.txt`（新專案為錯誤）

```
P:System.DateTime.Now;改用 IChurchClock 或 IClock
P:System.DateTime.Today;改用 IChurchClock.TodayInChurch
M:System.DateTime.ToLocalTime;改用 IChurchClock.ToChurchTime
P:System.TimeZoneInfo.Local;不得依賴伺服器時區
P:System.Globalization.CultureInfo.DefaultThreadCurrentCulture;不得讀寫程序全域預設文化
P:System.Globalization.CultureInfo.DefaultThreadCurrentUICulture;不得讀寫程序全域預設介面文化
```

- Plugin 專案另外加 `N:System.Drawing;沙箱不支援 GDI`。
- 若格式與 BannedApiAnalyzers 版本不合，以該套件文件為準調整，並保留理由文字。
- P0-04 已實測 5.6.0：setter 方法識別碼不會命中屬性指派，故依上述授權改為屬性識別碼，拒絕程序預設文化讀寫；兩個指派探測均須產生 RS0030。

### E.2　產生的 C# 程式碼格式

```csharp
// <auto-generated>由 tools\I18nCheck 從 SharedText.resx 產生，請勿手動修改。</auto-generated>
namespace SpeechMessage.Localization.Resources
{
    internal static class SharedTextData
    {
        internal static readonly string[] Cultures = { "zh-TW", "en", "qps-ploc" };
        // 每列：key, zh-TW, en（缺字為 null）, qps-ploc；依 key 的 Ordinal 排序
        internal static readonly string?[][] Rows = { /* ... */ };
    }
}
```

- 排序固定，使用 CRLF、UTF-8 無 BOM。
- 不使用 `DateTime.Now` 產生時間戳記，避免每次產生的內容不同。

### E.3　偽語系規則（`qps-ploc`）

- 每段文字轉成 `［` ＋原文＋`］`，再補 `ǂ` × `max(1, ceil(原文字數 × 0.4))`。字數不含 `{參數}`。
- `{name}` 這類參數原樣保留。
- 格式語系為 `en-US`。
- 只有 `AllowPseudoLocale=true` 時才能選用，正式環境禁止（P2-01 的啟動檢查）。
