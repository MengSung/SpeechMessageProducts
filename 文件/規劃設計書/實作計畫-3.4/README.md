## 3.4 只做三件事

1. **整併：** 3.3 實作期間核定的 12 項變更全部寫回正文（00 §13），不再有散落的「補充」段落。
2. **兩手放開：** Codex 全自主操作測試環境——D365 組織 goodshepherdback，以及 D365-9.1、D365-DC01 等測試主機（SQL 備份還原、服務、IIS、佈署、清理、驗收）。只有 00 §9 列的情況才找使用者。
3. **收斂：** 範圍凍結在 3.4 的 84 個工作包（原 83 包＋從 P2-01 移出的 R2 清零 P6-07）；每包有固定的完成定義（不得加碼）與時間盒（1 個工作天或 15 個提交）；做完就收工；新想法進「之後再說」清單；計畫只由使用者改版。

P0、P1 的成果全部保留，不重做。
