## 2. D365 9.1 實測事實（後續階段要遵守，詳見 90 附錄 A.9）

1. **新查閱欄的稽核旗標不會保留：** 9.1 的 `CreateOneToManyRequest` 忽略新建查閱欄的 `IsAuditEnabled`。建立後只對「本次剛建立」的欄位 ID 以 `UpdateAttributeRequest` 補開稽核；不得用來修改原有欄位。
2. **重複鍵錯誤碼：** 9.1 第二筆相同替代鍵回 `0x80040237`（DuplicateRecord），不是較新版本的 `0x80060892`；驗收以「差分控制」證明是唯一鍵擋下，而不是只看錯誤碼。
3. **解決方案根元件：** 新表的根元件 `rootcomponentbehavior=0` 已包含子元件，不要求另外產生子元件列；既有表（account、contact）逐欄核對元件 ID。
4. **net48 被拒：** 驗證器拒絕 net48 組件（以 `FormatException`／`0x80040216` 呈現）；net462 可註冊、可執行（P0-13）。
