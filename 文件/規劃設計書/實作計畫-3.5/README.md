# 方案整合與國際化：Codex 實作計畫 3.5（依設計 v3.4）

本資料夾是 Codex（或任何實作代理）逐步執行的實作計畫。設計依據仍是 E: 規劃資料夾的《方案整合NET10升級與國際化落地實施計畫書_v3.4_Plugin版_20261107.docx》、保姆級圖解 v3.4 與 drawio v3.4；**3.5 只改實作計畫，設計沒有改版。**

> 3.2、3.3、3.4 已依 `00` 第 14 節封存到 `文件\規劃設計書\_封存_請勿依據\`，只供查閱歷史，**不得作為依據**。

## 3.5 是精簡改版，只做三件事

1. **寫回已核定的提案：** 階段 2 審查一次交付的 PROP-002～007 全部寫進正文（00 §13），不再只記在進度頁。
2. **收斂階段 2：** 階段 2 已於 2026-11-09 驗收，收成一頁摘要；實機學到的 D365 與 LINE 平台事實寫進 90 附錄 A.9、A.10。
3. **不再卡在實機前一步：** 每個階段開工先做「前置缺項檢查」（00 §7.3），需要使用者的秘密、主機、權限一次列清楚。

範圍（84 個工作包）、架構、決定、完成定義、時間盒全部不變。一頁圖解見 `3.4到3.5變更一頁圖解.html`。

## 給 Codex 的一句話

一次最多兩包；照 WP 段落的測試與完成定義做到就收工，不要自己加碼；每個階段開工先把需要使用者的東西一次列清楚；提交後在固定 guard 驗證，驗收後才推送，推送後核對遠端 SHA；能自己在測試環境做的事就自己做，做完留一頁紀錄。
