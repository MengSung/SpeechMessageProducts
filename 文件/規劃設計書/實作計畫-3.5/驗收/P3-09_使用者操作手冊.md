## 第 1 件事：新增一筆 DNS 記錄（約 10 分鐘，生效要等幾分鐘到幾小時）

### 1-1　登入 DNS 管理介面

1. 用瀏覽器登入 Seednet 的網域／DNS 管理頁面（或你平常管理 `speechmessage.com.tw` 的地方）。
2. 找到 `speechmessage.com.tw` 的「DNS 記錄」或「主機記錄」清單。
3. 在清單中找到 **`goodshepherdback`** 這一筆，確認它的類型是 **A**、值是 **`220.134.52.83`**。新增的記錄就是照著它抄。

### 1-2　新增記錄

按「新增記錄」，填入：

| 欄位 | 填什麼 |
|---|---|
| 主機名稱（Host／名稱） | `linewebhook-test` |
| 類型（Type） | `A` |
| 值（IP 位址／指向） | `220.134.52.83` |
| TTL | 保持預設值 |

按「儲存」。**不要修改或刪除任何其他記錄。**

### 1-3　如果是別人幫你管網域，把這段話轉給他

```text
您好，請在 speechmessage.com.tw 的 DNS 新增一筆 A 記錄：
主機名稱 linewebhook-test，指向 220.134.52.83（與既有的 goodshepherdback 相同），TTL 用預設值。
其他記錄請不要變動。謝謝！
```

### 1-4　確認 DNS 有沒有生效（隨時可以檢查）

> 這一步**只檢查 DNS 記錄（門牌）**，不是檢查網站。LINE Webhook 網站要等 Codex 在 D365-9.1 上建立。在那之前，這個網址會先由同一台主機上既有的 D365 測試站回應，所以看到 D365 的頁面是正常的。

用瀏覽器打開：`https://linewebhook-test.speechmessage.com.tw`

| 看到什麼 | 代表什麼 |
|---|---|
| 出現任何頁面（**就算是 D365 登入頁或錯誤頁也算**），網址列有鎖頭圖示 | ✅ DNS 已生效 |
| 「找不到這個網站」「無法連上這個網站」 | ⏳ 還沒生效，過一陣子再試；超過一天還是這樣，回頭檢查 1-2 的四個欄位 |

> DNS 還沒生效也可以先做第 2、3、4 件事。Codex 會先在內部部署和測試，等 DNS 生效後再做 LINE 那一段。

## 第 2 件事：把虛擬機帳密存成加密檔（約 10 分鐘）

這一步讓 Codex 能進入測試虛擬機，而且 **你不用把密碼告訴任何人或貼進聊天**。
密碼會用 Windows 內建的加密（DPAPI）存起來：**只有這台電腦、目前這個 Windows 帳號**解得開，複製到別台電腦也打不開。

### 2-1　用系統管理員身分打開 PowerShell

1. 按鍵盤左下角的 **Windows 鍵**。
2. 直接打字：`PowerShell`
3. 在出現的「Windows PowerShell」上按 **滑鼠右鍵** → 選 **「以系統管理員身分執行」**。
4. 跳出「是否允許此應用程式變更你的裝置？」→ 按 **「是」**。
5. 會出現一個藍色（或黑色）視窗，**標題列有「系統管理員」字樣**，就對了。

### 2-2　貼上下面整段並按 Enter

把下面整段**全部複製**，在 PowerShell 視窗裡 **按滑鼠右鍵**（會自動貼上），再按一次 **Enter**。

```powershell
& {
    $ErrorActionPreference = 'Stop'
    $vms = Get-VM | Sort-Object Name
    Write-Host "這台電腦上的虛擬機：" -ForegroundColor Cyan
    $vms | ForEach-Object { Write-Host ("  {0}（{1}）" -f $_.Name, $_.State) }
    $cred = Get-Credential -Message '請輸入 D365 測試虛擬機的管理員帳號與密碼（帳號格式：網域名稱\帳號）'
    if (-not $cred) { Write-Host '已取消，沒有存檔。' -ForegroundColor Yellow; return }
    $ok = @()
    foreach ($vm in ($vms | Where-Object State -eq 'Running')) {
        try {
            $name = Invoke-Command -VMName $vm.Name -Credential $cred -ScriptBlock { $env:COMPUTERNAME } -ErrorAction Stop
            Write-Host ("  [成功] {0} → 主機名稱 {1}" -f $vm.Name, $name) -ForegroundColor Green
            $ok += $vm.Name
        } catch {
            Write-Host ("  [失敗] {0}：{1}" -f $vm.Name, $_.Exception.Message) -ForegroundColor Yellow
        }
    }
    if ($ok.Count -eq 0) {
        Write-Host '這組帳密登入不了任何一台虛擬機，所以沒有存檔。請確認帳號格式（網域名稱\帳號）和密碼後，再貼一次這整段。' -ForegroundColor Red
        return
    }
    $dir = Join-Path $env:USERPROFILE '.speechmessage'
    New-Item -ItemType Directory -Force -Path $dir | Out-Null
    $path = Join-Path $dir 'test-vm-admin.clixml'
    $cred | Export-Clixml -Path $path
    Write-Host "已加密存檔：$path" -ForegroundColor Green
    Write-Host ('可登入的虛擬機：' + ($ok -join '、')) -ForegroundColor Green
}
```

### 2-3　輸入帳密

1. 會跳出一個 **Windows 登入小視窗**。
2. 「使用者名稱」填虛擬機管理員帳號，例如 `網域名稱\Administrator`。
3. 「密碼」填密碼 → 按 **確定**。
4. 等十幾秒，程式會逐台試登入。

### 2-4　看結果

| 看到什麼 | 怎麼做 |
|---|---|
| 綠字「**已加密存檔**」，以及「可登入的虛擬機：…」 | ✅ 完成。把「可登入的虛擬機」那一行的名稱記下來（不含密碼），第 4 件事會用到 |
| 紅字「這組帳密登入不了任何一台虛擬機」 | 帳號或密碼不對，重新貼一次 2-2 的整段再試；帳號前面要加網域名稱 |
| 紅字錯誤，內容有「Get-VM」或「權限」 | 視窗不是用系統管理員身分開的，回到 2-1 重來 |
| 「這台電腦上的虛擬機」底下是空的 | 虛擬機沒有在這台電腦上，或 Hyper-V 沒開；把畫面截圖給 Claude 或 Codex 看 |

做完就可以把這個 PowerShell 視窗關掉。
