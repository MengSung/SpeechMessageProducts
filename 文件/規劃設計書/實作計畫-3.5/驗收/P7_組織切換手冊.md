## 6. 回復

非預期寫入／錯誤／完成不明先停止worker並drain，再用當次switch-log回復。XAML以原字串還原，不重序列化。

```powershell
dotnet run --project SpeechMessage.Dynamics.Deployment -c Release --no-build -- rollback --org <name> --from <switch-log.json>
dotnet run --project SpeechMessage.Dynamics.Deployment -c Release --no-build -- verify --org <name>
```

export比狀態、mode／secure presence；流程逐位元組比較。verify不驗秘密實值、不是金鑰輪替。
回復失敗保留證據，不重試未知寫入；依完整export與資料庫備份復原，按07A §7一次回報選項。測試結束新步驟全停、舊啟用0、待辦基線、測試資料／流程0、trace原值。
