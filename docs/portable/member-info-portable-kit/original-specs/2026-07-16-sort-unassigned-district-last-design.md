# 區長未填節點排序設計

## 目標

會友資訊樹狀畫面的區域節點依下列順序顯示：

1. 所有已填區長的區域。
2. 顯示為「區長未填」的區域。
3. 獨立的「無小組」節點。

因此畫面上的最後三段會是：最後一位已填區長（例如「區長：區長乙」）、`區長：區長未填`、`無小組`。

## 排序位置

排序由 `DistrictTreeBuilder` 在建立 `Districts` 集合時完成，不在 Razor 或 JavaScript 重新排序。`Ungrouped` 本來就是獨立欄位，前端會在所有 `Districts` 之後附加「無小組」，因此只需把顯示名稱為 `UnknownRaceLeaderName` 的區域排到 `Districts` 最後。

## 排序規則

- 第一排序鍵：是否為 `UnknownRaceLeaderName`；已填為 0，未填為 1。
- 第二至第四排序鍵維持現況：牧區名稱、區長名稱、區長鍵值。
- 如果資料中有多個顯示為「區長未填」的區域，彼此仍依原有三個排序鍵保持穩定且可預期的順序。
- 小組排序、會員計數、權限與搜尋資料不變。
