# 會友資訊版面與搜尋互動設計

## 目標

維持現有會友資訊的權限與資料來源，改善組織層級辨識、搜尋回饋及手機表格操作。採用使用者確認的方案 A：區長用較大的靛藍字，小組長用青綠字。

## 組織版面

- 牧區名稱是選填標題；空白或既有的「(未填牧區)」哨兵值都不渲染。
- 區長姓名與「本區 N 人」徽章放在同一行，使用靛藍主色與較大字級。
- 小組長姓名與「N 人」徽章放在同一行，使用青綠主色與較小字級。
- 人數徽章不再以獨立彈性欄靠右，窄螢幕時會跟隨姓名自然換行。

## 搜尋狀態

搜尋狀態只有四種：`idle`、`searching`、`results`、`error`。

- `idle`：呈現使用者原本的樹狀檢視。
- `searching`：保留原 DOM 狀態但以全頁遮罩禁止其他操作；搜尋按鈕提升到遮罩上方，變成紅色「停止搜尋」。
- `results`：搜尋結果 DataGrid 取代樹狀檢視與分頁；一筆、多筆及零筆都屬於完成狀態。
- `error`：結果區顯示可理解的錯誤訊息，並可返回原檢視。

開始搜尋前保存搜尋前畫面所需狀態。取消搜尋會 abort 目前 AJAX，移除遮罩並恢復原畫面；搜尋完成後按「返回會友資訊」也使用同一個恢復流程。輸入框按 Enter 與搜尋按鈕共用同一入口，避免兩套狀態不一致。

## 搜尋資料流

後端搜尋回應直接提供已通過既有範圍授權的會友資料列，前端不再先取得小組 ID 再自動展開多個小組。結果使用與小組成員相同的列模型及欄位格式，以支援多筆結果、零筆結果、照片批次載入及姓名明細連結。

新的搜尋不更改原樹資料，也不依賴重新載入樹來返回，因此取消或返回時可保留原本頁次與展開狀態。較晚回來的舊請求以請求 token 忽略，避免快速搜尋或取消後被舊回應覆蓋。

## 全頁遮罩

遮罩覆蓋整個會友資訊頁面可見區域並帶有 spinner、友善文字及半透明背景。「停止搜尋」按鈕的層級高於遮罩，是搜尋期間唯一可操作的頁面控制項。動畫遵守 `prefers-reduced-motion`。

## 表格與手機手勢

全教會、小組成員與搜尋結果三種 DataGrid 共用欄位與響應式規則：

- 關閉 DevExtreme `columnHidingEnabled`，不產生「…」自適應欄。
- 表格設定內容最小寬度，外層容器採 `overflow-x: auto`。
- 容器啟用原生慣性捲動與水平手勢，不加入會攔截 touchmove 的自訂拖曳程式。
- 保留水平 scrollbar 作為位置提示與桌機備用操作。
- 頁面仍可垂直滑動；手機瀏覽器依手勢方向決定水平表格或垂直頁面移動。

## 錯誤與空狀態

- 零筆：顯示「沒有搜尋到符合的會友」，仍提供返回原檢視。
- 無權限：顯示「無權搜尋此範圍」。
- 其他失敗：顯示「搜尋失敗，請稍後再試」。
- 取消：不顯示錯誤，完整恢復搜尋前狀態。

## 測試

- 後端單元測試：搜尋列授權／去重、零筆、多筆與未填牧區輸出。
- View 結構測試：搜尋／停止／返回狀態、全頁遮罩、結果容器、關閉欄位隱藏、水平 overflow 與 touch 設定。
- 建置與既有 MemberInfo 測試：確認無編譯退步。
- 實際畫面：桌機搜尋／取消／返回，窄螢幕三種表格手指左右滑動且沒有「…」欄。
