# 會友資訊載入動畫設計

## 目標

將會友資訊的純文字「載入中...」改成持續有動態回饋的友善載入卡片，讓超過 10 秒的等待不會被誤認為畫面當機。

## 選定方案

採用純 CSS 的「親切動畫卡片」：柔和漸層底色、三顆依序跳動的彩色圓點、清楚的主標題與說明文字。等待超過 6 秒時，說明文字改為「資料還在傳送中，畫面沒有當掉，請再稍候一下」，明確回應長時間等待的疑慮。

同一個載入元件套用於：

- 首次載入區／小組樹
- 展開小組後載入會友名單
- 開啟會友詳細資料彈窗

## 互動與無障礙

- 載入卡片使用 `role="status"`、`aria-live="polite"` 與 `aria-atomic="true"`。
- 動畫元素標記為 `aria-hidden="true"`，讀屏只朗讀文字。
- 使用 `prefers-reduced-motion: reduce` 時停用跳動與漸層動畫，但保留完整文字提示。
- 固定最小高度，減少載入狀態切換造成的版面跳動。

## 邊界

不修改 AJAX API、30 秒逾時、失敗訊息、權限訊息與重試流程。動畫完全由現有 Razor、CSS 與 JavaScript 組成，不增加圖片或第三方相依套件。

## 驗證

- 契約測試確認三個載入入口均使用共用動畫元件。
- 契約測試確認無障礙屬性、長等待文案及 reduced-motion 規則存在。
- 執行 MemberInfo 測試、方案建置與 Razor JavaScript 語法檢查。
- 在 `http://localhost:<本機連接埠>/MemberInfo/Index` 實際確認初始、小組及明細載入畫面。
